# Backlog of deferred items

Status: Informative. Nothing in this file may be implemented before its target version (see `CLAUDE.md`, scope guard). Sources: R1, R2, R3 are the three external design reviews (`reviews/triage.md`); D is the original design. The owner's design decisions of 2026-10-01 are cited by their ids (V2-n for the memory model, FW-n for fixed-width integers) and recorded in full in the linked issues. Each row links to its GitHub issue, the unit of work (`CLAUDE.md`, "Work rules").

## Opened for v0.2

These rows are in scope since Leonardo opened the v0.2 scope on 2026-10-01 (charter §5b). Each is implemented only after its ADR and spec text are merged: ADR 0055 for the native backend, ADR 0056 for the memory model, ADR 0057 for fixed-width integers, ADR 0060 for recursive kinds, ADR 0062 for effect polymorphism, ADR 0063 for the language server, ADR 0065 for structured concurrency and ADR 0066 for constraints on generics.
