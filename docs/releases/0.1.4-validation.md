## Known deviation (amd64 emulation)

`linux-test` has one failing test, `runtime::a_depth_beyond_the_address_space_is_a_usage_error`, and every other test of the workspace passes (`--no-fail-fast`). The test runs `una run --max-depth 100000000000`, which must exit 2 with a usage error: on a real kernel the stack that depth asks for cannot be reserved. Under the amd64 emulation of an arm64 Mac, the process is killed by a signal instead. The failure comes from the emulation, not from this release:
