# History of v0.1

Status: Informative. These files record how v0.1 was built. They are history: nothing here is normative, and later work does not update them, except the decision log, whose open entries the owner answers.

| File | What it records |
| --- | --- |
| `OVERNIGHT.md` | The instructions of the autonomous run that built M1 to M10, and its progress |
| `runs/M1-plan.md` to `runs/M10-plan.md` | The plan and self-review checklist of each milestone |
| `runs/v0.1-closure-plan.md` | The closure run: how the independent review's findings and the owner's answers were applied |
| `open-decisions.md` | The decision log: every choice the specification did not dictate, with its answer. D-133 and later await the owner's answer |
| `morning-report.md` | The status report of the autonomous run |

The independent review of v0.1 is in `docs/reviews/v0.1-review/`, and fix requests are in `docs/fixes/`.
