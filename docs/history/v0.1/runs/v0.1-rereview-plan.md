### Gaps the sweeps found, all fixed

- **Label leak:** a `let`-bound lambda returning a secret, passed to an operation that accepts public. Sinks now join every label of the argument's type (`spec/07 §7` rule 4).
- **Label leak:** `Src[Int]` joined with `Src[secret Int]` by `if`, `when` or a list lost the secret. Fixed by checking branch joins and list elements as flows (ADR 0046 rule 3).
- **False rejections:** `mk3[T](s: Sink[T]) -> Sink[T] = s`, and `Feed(get: fn() -> 2)` built for a `Feed[secret Int]` (D-163, D-166).
- **Soundness bug, outside the two root causes:** records of the standard library, which has its own source database with the same file ids, overwrote the package's records at the same offsets, so an ADR 0037 obligation could vanish depending only on byte offsets. The standard library's records are now kept in their own table, and a test pads a program over 2700 offsets.
- **Refinement gap:** handler operation results skipped function-type refinements. They are now checked like a function's result.
