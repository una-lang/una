## 3. The class-level sweeps

### Label computation: type form against consumer

Every cell is `tests/conformance/security/sweep_label_<form>_<consumer>.una`, with `-- test: ... (label sweep)`.

| Form | `==` | order, `in` | interpolation | sink | generic result | prelude results | handler result | function value | condition |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| record with a labeled field | yes | yes (1) | yes | yes | yes | yes (2) | yes | yes | yes |
| sum with a labeled variant field | yes | yes (1) | yes | yes | yes | yes (2) | yes | yes | yes |
| generic kind over a labeled type | yes | yes (1) | yes | yes | yes | yes (2) | yes | yes | yes |
| nested generics (3) | yes | yes (1) | yes | yes | yes | yes (2) | yes | yes | yes |

| function values | yes (4) | yes (4) | yes (4) | yes | yes | yes | yes | yes | yes |

1. Ordering a kind itself is rejected by construction (U2001), in the same file.
2. `contains`, `first`, `at`, `first_where`, `filter`, `map`, `fold`, `is_some`, `is_ok`, `append`, `or_else`, `is_empty`, `sum`, `min` and `max`.
3. `Box[List[secret Int]]`, `Option[Box[secret Int]]`, and a record inside a record.
4. The operation on the value itself is rejected by construction (U2001); the file checks the labeled result.

Recursive and mutually recursive kinds: `security/sweep_label_recursive_kinds.una`.

1. A list element cannot be refined (ADR 0040), and a literal has no label or function type.
2. Their results are `Int`, and `List[Pos]` is ill-formed, so only labels apply.
3. Added in closure round 3 (ADR 0050, final review F-001): `sweep_flow_oparg_<source>`. S checks the flow into a function parameter of the operation's parameter type (U4001) and the sink of a data argument (U4003); V checks refinements (U5001).

A literal has no label or effect, so that column has no S case. The sites of an operation call (a handler operation body, a function run under `with`, an operation on a handler installed by `with`, and a `do` line under `given`) are in `security/op_argument_sites.una`.

### Gaps the sweeps found, all fixed

- **Label leak:** a `let`-bound lambda returning a secret, passed to an operation that accepts public. Sinks now join every label of the argument's type (`spec/07 §7` rule 4).
- **Label leak:** `Src[Int]` joined with `Src[secret Int]` by `if`, `when` or a list lost the secret. Fixed by checking branch joins and list elements as flows (ADR 0046 rule 3).
- **False rejections:** `mk3[T](s: Sink[T]) -> Sink[T] = s`, and `Feed(get: fn() -> 2)` built for a `Feed[secret Int]` (D-163, D-166).
- **Soundness bug, outside the two root causes:** records of the standard library, which has its own source database with the same file ids, overwrote the package's records at the same offsets, so an ADR 0037 obligation could vanish depending only on byte offsets. The standard library's records are now kept in their own table, and a test pads a program over 2700 offsets.
- **Refinement gap:** handler operation results skipped function-type refinements. They are now checked like a function's result.
