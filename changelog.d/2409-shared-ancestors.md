- **The manifest above a loose file is looked for only where no other user can write, and a refused path dependency gives back its share of the bound** (#2409, #2410, #2411, #2412, `spec/30 §1` rule 4; kind: U7008). The search for the manifest above a loose file walked up to `/`. A directory, a FIFO or a manifest at `/tmp/una.toml`, which any user can create, therefore failed or chose the edition of every other user's check below it. The search now stops at the first directory that is world-writable or owned by another user than this user and the superuser. A manifest owned by another user, or a link to one, also ends the search unread (#2410, #2412). An error other than "not found" at a manifest's path is now refused, never taken for no manifest. A path dependency refused after some of its modules were read no longer keeps their bytes in the bound it shares with the root, so the next dependency is not refused falsely (#2409). The test of an unreadable `ita.una` skips the mode-000 case when the user reads it anyway (a superuser), and adds a FIFO case that holds for every user (#2411). O(depth of the path) for the search, as before.
