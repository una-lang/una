- **The registry service names the root a checkpoint was signed under, and keeps it when it signs a size again** (#1561, `spec/30 §11` rule 9 and `§16` rules 5 and 9). Each checkpoint carries `ita-root <n> sha256:<hex>`; after a root rotation and a restart, a size whose checkpoint is stored keeps the version, key and bytes it was first signed with, and the rotation takes effect from the next entry.
