- **Security: writes under a package no longer follow a planted link** (#1160, advisory UNA-SA-018). `una fmt`, `una fix`, `una migrate`, `una ita lock` and `una fmt ita.una` used to write a temporary file at a fixed name next to the file they replace (`.<name>.fmt-tmp`, `.<name>.tmp`), following a symbolic link at that name. A repository could commit such a link and have a formatting run overwrite a file outside it. The temporary file is now created exclusively, under a name unique to the write, with mode 0600 until it takes the destination's permissions, then synced and renamed. A source that is a symbolic link is still written through onto the file it resolves to, but only when that file and its directory are inside the package: a link that leads outside it is refused, naming where it leads. `una build` follows the same rules: it refuses a `target` or `target/una` that leads outside the package and a link at the executable's name, checked before the system linker starts; the linker writes into a private directory of its own, and the executable is renamed into place, so no `<name>.o` is written next to it any more. The proof cache's directories and entries (`.una/cache/proofs`) are written the same way: a `.una`, `.una/cache` or `.una/cache/proofs` that leads outside the package makes the cache store nothing. All of these writes now share one helper.
