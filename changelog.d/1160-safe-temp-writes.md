- **Security: writes under a package no longer follow a planted link** (#1160, advisory UNA-SA-018). `una fmt`, `una fix`, `una migrate`, `una ita lock` and `una fmt ita.una` used to write a temporary file at a fixed name next to the file they replace (`.<name>.fmt-tmp`, `.<name>.tmp`), following a symbolic link at that name. A repository could commit such a link and have a formatting run overwrite a file outside it. The temporary file is now created exclusively, under a name unique to the write, then synced and renamed: for a replacement with mode 0600 until it takes the destination's permissions, and for a new file under the umask, as before. A source that is a symbolic link is still written through onto the file it resolves to, but only when that file and its directory are inside the package: a link that leads outside it is refused, naming where it leads. `una build` creates `target/una` one level at a time, refusing a `target` or `target/una` that leads outside the package, and refuses any link at the executable's name or at `<name>.o`. The linker now writes the executable, beside its object file, in a fresh private directory that `una build` creates inside `target/una` (or inside the directory `--out` names: a plain relative `--out` is rooted at the current directory and created one level at a time in the same way, an absolute one or one with `..` is created as given) and always removes; the executable is then checked to be a regular file there, synced and renamed into place, so a link planted at the final name while the linker runs is never written through. Before, it wrote the object with a write that follows a link, and the linker wrote the final path directly. A `target` deliberately linked to another volume now needs `--out` with an absolute path there, or one with `..`. The proof cache stores its entries the same way, without the fsync since a torn entry fails its tag and is solved again, stores nothing when `.una`, `.una/cache` or `.una/cache/proofs` is a link that leads outside the package, and replaces a link at an entry's name instead of following it, even one that leads inside the package.
