- **`scripts/doc-links.py` reads headings in block quotes and list items** (#843). It reads a document's block structure as the website does for headings and code: block quotes and list items, nested either way, fenced code with backticks or tildes, which ends with its container, and indented code. A heading inside a quote or a list item (`> ## Amendment`, `- ## Step`) gets the website's id, and later headings keep theirs; code inside a container is skipped by the link check too. The site gate's comparison of heading ids with the website found the difference.
