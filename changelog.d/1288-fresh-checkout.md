- **A fresh checkout builds and passes its tests with one setup command** (#1288, #1287, #1278, ADR 0124, `docs/compiler/testing.md` §3). `eval "$(scripts/z3-library.sh --export)"` builds the Z3 library into the cache when it has none for this machine's toolchain and sets `UNA_Z3_LIB`, which `CLAUDE.md` and the testing guide now name; a build of `una-z3` without it warns that tier-1 tests will fail with U5003. The solver child's handshake window and deadline now start at the spawn, after the parent has resolved what it needs, and the toolchain's own test harness runs its `una` once before its first solver child, so the operating system's first launch of a newly linked `una` (more than a second for the debug build on macOS) no longer falls inside the 2-second window of that child; a shipped `una` re-executes the file it already runs from and never paid it. The determinism test of the JSON documents compares runs that all read a warm proof cache, and a new test pins that a cold and a warm report differ only in `obligations.cached` and `tcb.solver_confinement`.
