- **`una ita publish`, `yank`, `audit`, `watch`, `bundle` and `unbundle`** (#999, ADR 0122 rules 33, 36.2 and 40 to 43, `spec/30 §14`). `publish` refuses what rule 43 names and any diagnostic of a tier 1 check, builds the archive, writes and signs the release statement against the verified state of its name, refusing authority that grows within a major line, and sends it through a directory (`--upload file:///...`); `yank` sends a signed yank. `audit` reports the new code U7014, once per package, for a locked release that is yanked, under an advisory, or signed after a stated compromise, and for a pending recovery, a key change or a transfer since the lock's resolution point. `watch` follows an owner's chains from a position kept in Itaoca and reports a registry's broken promise to log a submission. `bundle` and `unbundle` carry a lock's registry packages to an air-gapped machine, where every package is verified against the lock before Itaoca is written. `mirrors.una` lists mirrors per source, each verified as its source would be. Plain `http://` is refused wherever a URL is read. `una ita add` names the source that serves a package's owner itself. No command opens a connection: `publish`, `yank` and `watch` need the registry client, which joins later, and stop before sending anything; until then `audit` reports each registry package as not verified, U7010.
