- **The proof cache key's owner check reads the effective user directly** (#1894). The check that a key file belongs to the user (#1164) read the user by creating and removing a probe file in the temporary directory on every command that verifies; it now reads it through the toolchain's one binding of `geteuid`, which is the user that owns a file the process creates (a test keeps the probe and checks that both agree). The rule is unchanged: a key file owned by anyone else is refused. `una check` of a small package retires about 0.85 million fewer instructions of 48.4 million (1.8%), and no longer writes to the temporary directory.
