- **A `sanitize` release gate checks the native runtime with AddressSanitizer and Miri** (#766). `scripts/sanitize.sh` builds the runtime with AddressSanitizer and runs the native equivalence test, every runnable program, against it, with a canary that fails the gate when AddressSanitizer is not active; and it runs the runtime's unit tests under Miri, with the set of tests Miri does not run pinned by name in `scripts/sanitize-miri-ignored.txt`. It uses a nightly Rust pinned in `scripts/check-toolchain.toml` (installed by `scripts/install-check-toolchain.sh`) for checking only, never to build an artifact, and fails when that toolchain is missing or differs. macOS only for now. Three tests that do not finish under Miri are tracked in #778.
