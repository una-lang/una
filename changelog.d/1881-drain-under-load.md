- **A test of the drain under load** (#1881, ADR 0123 rule 18, `spec/31 §6` rule 9 and §7 rule 4). A package with a `serve` section, under `una run` and as the executable of `una build`, takes SIGTERM with 32 requests in flight (200 with `UNA_DRAIN_REQUESTS=200`): each request is answered once and completely, `200` by its `handle` or `503` with `Retry-After: 1` by the host, a later connection is refused, `on_stop` runs last, the run ends with exit code 0 before the hard stop, and its port is free.
