- **The serve tests hold the test build of `una` they run** (#2201). `crates/una-cli/tests/serve_runs.rs` and the scripted test of `serve_live.rs` ran `CARGO_BIN_EXE_una`, the path `target/<profile>/una` where each cargo command puts the `una` it built last: the tests' build with the `test-hooks` feature, or a plain one. A plain build of `una-cli` in the same target directory during a run (`cargo build`, `cargo run`) replaced it, and the later cases of a running test met a `una` that refuses `--serve-script` ("the scripted connections ... do not run in this release yet"). The tests now run a hard link to the file taken when the test process starts, checked to hold both test-hook markers, so a later replacement changes nothing; a path that already holds a plain build fails at once with the cause. A new test replaces the path as cargo does and checks both. No behavior of `una` changes.
