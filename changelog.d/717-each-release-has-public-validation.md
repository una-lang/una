- **Each release has a public validation summary, which the installer reads from the repository** (#717, `docs/release-gates.md`). `scripts/release-summary.py` writes the summary of a validation record by a fixed template: the commit, the run's date and platform, the toolchain, each gate's result and seconds, the archives' SHA-256 and the verdict, with every field checked against its shape. It is committed as `docs/validation/<version>.md` and is the release's notes and an asset. `install.sh` reads it from the release's tag, then from `main`, never from the release's assets, accepts a repacked macOS archive of v0.3.3 to v0.3.13 only as `docs/validation/repacked.md` pairs it with the gated digest, and says when an archive was withdrawn or a release has no summary. `docs/releases/validation.md` is now `docs/release-gates.md`.
