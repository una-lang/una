- **The installer: macOS on arm64 only, and 0.4.0 or later** (#1819). This release ships for macOS on arm64; on Linux `install.sh` stops with "Linux is not available in this release yet", because the Linux build of the solver that `una` carries is not yet pinned to a reproducible digest and `una build` does not yet link Linux executables itself. The installer also refuses a `UNA_VERSION` before 0.4.0, compared as numbers (0.10.0 is after 0.4.0), and anything but MAJOR.MINOR.PATCH: a release before 0.4.0 needs a separate Z3, which the installer no longer installs, so its `una check` could prove nothing. The README, Getting started and the known limits say so.
