- **The documentation says that the solver is built into `una`** (#1820, ADR 0124). `una explain U5003`, the README, Getting started, Una for agents, the language guide and the `verification.lock` page no longer tell you to install Z3 or put it on `PATH`: the release `una` carries Z3 and never looks for a `z3` program. U5003 now explains its four causes: a lock that pins another Z3 version, a development build with no solver built in, a solver that could not be confined (such as one run as root, with the workaround), and a failed handshake. Building from source now runs `eval "$(scripts/z3-library.sh --export)"` first, without which the `una` it builds has no solver. The pages also say that on macOS arm64 `una build` links with its own linker and needs no `cc`, that the installer needs no `unzip`, and, on the known-limits page, which foreign code the `una` binary holds.
