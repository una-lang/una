- **Native: the result of an unchecked `Int` operation always has its tag bit** (#2245, ADR 0055 NB-3, ADR 0112 EL-2, lane S): where the range facts prove both operands and the result of `+`, `-` or `*` in the tagged range, the Cranelift build still computes the operation as a wrapping machine instruction with no tag test and no promotion, and now forces bit 0 of its result, one `orr` per site. On tagged operands the word is already odd, so no result changes; if a range fact were ever wrong (a verifier, solver, proof-cache or runtime bug) and an operand were a handle, the result is now an `Int` immediate, a wrong value at worst, never a word that names a heap object. Defense in depth: no correct program's output changes.
