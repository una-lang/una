- **An `Int` of more than 4300 digits is never written as text** (#923, security, `spec/11 §7`, in every edition). Interpolation, `to_text`, `to_json`, traces, outputs, failures and test reports write an `Int` in decimal, which takes quadratic time in its digits, while a few multiplications build one of millions of digits. Both engines now refuse such a write before any conversion, in O(1) from the integer's bit length, and abort the run with U6003, `an integer of more than 4300 digits is written as text here, past the limit of a run`, at the interpolation, the call or the operation; the final value or failure of `main` aborts with no position, and a test's report names the value instead. The bound is that of parsing (#914), so every integer a text can write can be written back; #1223 lifts it with a subquadratic conversion once Una's own big integer (#1093) lands.
