- **The `hunt` release gate's oracle covers `together`** (#807). A new operator of family C gives the two-run oracle programs where `together` could let a secret decide what an observer sees: tasks over secret elements, a secret branch, secrets sent by tasks, a block under a public condition, and a fan-out whose size the secret decides. Their public output must not move with the secret, and the native sample now compares task runs of generated programs too. A form the checks reject is kept as a must-reject probe. A lexical or syntax code on a generated program, or a must-reject program rejected without its expected code, now fails the gate as a generator's error, with a canary.
