- **U3021 gives one narrowed grant per requirement** (#2213, `spec/13 §3`, ADR 0093 rule 6): when a callee has two requirements of one capability, such as `@a: Prices[price]` and `@b: Prices[set]`, the repair narrows each to the operations its own requirement declares, `with @a = @full[price], @b = @full[set]`, instead of giving the first one both operations and saying nothing of the second. When the ceiling withholds one requirement's operations, the handler route names that requirement and keeps a narrowed grant for the others. When the excess comes from a granted handler's own `uses`, the repair names that handler instead of repeating the grant already written. Inside a `together` branch, U3013 now advises the named function for a call in a one-line `if` or a handling clause, since a branch is one `let`. Which programs check is unchanged. A dated amendment of ADR 0093 rule 6, stating that a handler within the ceiling keeps both, is Proposed for the Owner's decision.
