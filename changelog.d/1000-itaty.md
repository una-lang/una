- **The Itaty registry service** (#1000, ADR 0122 rules 34 to 46, `spec/30 §16`). A new crate, `una-itaty`, that logs release statements, yanks, advisories and owner key events in a transparency log only after verifying them: signatures by keys valid at that point, each name's chain, the name rules, immutability, needs already logged, rule 26, and the statement against its archive, whose authority and trust it computes from the code. It serves the log as C2SP tiles, the name map as content-addressed tiles, archives by digest, signed checkpoints with the witnesses' cosignatures it collects, and signed promises, over HTTP/1.1 on the standard library, from a file-backed store. A witness that replays the log and the map before it cosigns is included. An end-to-end test publishes with the client's code and verifies every proof with it.
