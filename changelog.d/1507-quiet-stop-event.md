- **Security (S-39): code under a `secret` branch no longer shows in the trace through the events the runtime appends by itself** (#1507, `spec/26 §6` rule 4). A host stop, a budget, SIGTERM or `--deadline` that ended a `for ever` under a program counter above `public`, a `within` whose deadline cut its loop there, or a failing `tasks` statement that cancelled its tasks there, in the code itself or in what it calls, appended a `stop`, `timeout` or `cancelled` event and moved the `seq` of every later event, so the number of events revealed the secret. Such code now appends none, in both engines. The run-wide budget of `--stop-after-iterations` is S-36, and a `start` under a `secret` branch inside a public `tasks` statement is #1512.
