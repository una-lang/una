- **Security (S-39): a `for ever` under a `secret` branch no longer shows in the trace** (#1507, `spec/26 §6` rule 4). A host stop, a budget, SIGTERM or `--deadline`, that ended a `for ever` under a program counter above `public`, or inside a call of a `diverges` function under one, appended a `stop` event and moved the `seq` of every later event, so the number of events revealed the secret; such a loop now appends none, in both engines.
