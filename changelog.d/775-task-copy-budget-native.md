- **A copy between tasks over the memory budget is U6003 in native code too** (#775). Native code copies a value between the heaps of a `together` block's tasks, at the fork and at the join, where the interpreter shares it. The copy was made in one step, so under `--max-memory` it could grow past the allocator's hard ceiling and the executable aborted on a signal where `una run` reported U6003. Each copy now checks the budget as it grows and ends the run, or stops the task, with U6003 at the block.
