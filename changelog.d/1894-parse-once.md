- **The command line is parsed once per `una` process** (#1894). Building the command line parser twice was a fixed cost of every `una` invocation: about 0.65 million instructions of the 40.8 million that `una check` of a small package retires (1.6%). A command line that does not parse is parsed again to report its error, as before, and a check with no obligation still starts no solver child, which a test now pins.
