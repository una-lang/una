- **The release gate checks Una by Example** (#733). When the website that `site/website.lock` pins names a commit of una-lang/una-by-example in its `learn.lock`, the `site` gate clones that repository at that commit, builds its download archives, and runs its `scripts/check.py` with the release's `una`: every example's outcome, each Try it change and every archive. The website then builds its Learn section, `/learn/`, from the clone, and the gate fails unless it does. A website without `learn.lock` is built as before, and the gate says the examples were skipped.
