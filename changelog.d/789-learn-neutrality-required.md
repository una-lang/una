- **The release gate checks the Learn pages for neutrality, and handles its patterns more strictly** (#789). The `site` gate checks every text file of Una by Example, English or translated, against the neutrality pattern with `grep -E`, naming any match by path only, and a run without the pattern stops unless `UNA_GATES_UNCHECKED=1` marks it as not for publication. `scripts/release-gates.sh` reads the neutrality pattern from `UNA_NEUTRALITY_PATTERN` or the Keychain item `una-neutrality-pattern`, as it reads the privacy pattern. Both patterns now reach the steps that apply them on a pipe, never in an environment or an argument. Each must be a valid extended regular expression that matches a fixed canary (`docs/release-gates.md` §3), so a pattern that matches nothing stops the run. The script refuses to run under a trace, and a run without either pattern says in its summary that it is unchecked and is never published. A pattern that grep cannot apply now fails the docs bundle instead of marking every file neutral.
