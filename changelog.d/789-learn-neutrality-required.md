- **The release gate requires the neutrality pattern for the Learn pages** (#789). The `site` gate's Learn step runs una-by-example's `check.py` with `--require-neutrality`, so every page of Una by Example, English or translated, is checked against the neutrality pattern, which `scripts/release-gates.sh` reads from `UNA_NEUTRALITY_PATTERN` or the Keychain item `una-neutrality-pattern` as it reads the privacy pattern; a run without it stops before any gate unless `UNA_GATES_UNCHECKED=1` marks it as not for publication. The website is built with `UNA_LEARN_DRAFTS` unset, so draft translations never reach it.
