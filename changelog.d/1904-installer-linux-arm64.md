- **The installer: Linux on arm64 with glibc 2.39 or later** (#1904). `install.sh` installs the `aarch64-unknown-linux-gnu` archive on Linux on arm64. Before anything is downloaded it refuses a musl system (Alpine and others), a glibc below 2.39 (compared as numbers), a system whose glibc version `getconf GNU_LIBC_VERSION` does not show, Linux on x86_64 (not shipped in this release), and every other system. After installing on Linux it says that `una build` needs a C compiler on `PATH` as `cc` (`una check`, `test` and `run` do not), that the executables it writes link the system's glibc dynamically, and that `una check` refuses to run as root, which it also says to root on macOS. Tests on fake machines show each case, that a refusal downloads nothing, and that the installer offers exactly the targets of `scripts/release-targets.txt`.
