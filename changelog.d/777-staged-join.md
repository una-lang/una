- **A `together` block joins its tasks batch by batch, copying one result at a time** (#777, ADR 0113 step 3). In native code, each batch of tasks has its own join: the block adopts the batch's events in task order, then copies the results in one task at a time, each task's thread and heap gone before the next one copies out. At its deciding batch's join, a block that aborts copies no result, a failing block copies only the deciding failure value, and a block whose own task was cancelled copies nothing; a failure leaves the later batches unforked. The block keeps one count instead of a cancellation flag per task, and reads each task's closure or element when it forks it. A task that stops with U8001, an internal error of the runtime, now decides its block before any failure or abort, whatever its index, and cancels every other task of the block, the lower-indexed ones included, so the run ends with U8001 once those tasks reach a check: a task inside an operation in progress, a handler's or the host's, sees the cancellation when that operation returns. The interpreter does not change.
