- **The runtime is tested against words the generated code never passes** (#766). A test calls every entry point of the native runtime's export table with boundary words (every tag pattern, freed and out-of-table handles, objects of the wrong kind) and fixed-seed pseudo-random ones, and requires each call to return a word or count a fault, never to panic, with the runtime still usable after. The same calls run again inside a started run, with its heap and a memory budget, where a call may also end the run as the model says (U6003, U8001) but never on a signal; this phase found the two divergences fixed in #773 and #775. It runs on every change, and `docs/security/tcb.md` records it.
