- **Started tasks that install handlers compare task by task in both engines** (#1542, `spec/27 §8` rule 4, `spec/16 §5`). Installations are numbered run-wide in the order they happen, so under the real clock two started tasks that both install handlers may interleave their numbers natively, where the interpreter gives each task its numbers in turn; the comparison of the two engines under the real clock now sets aside one renumbering of the run's installations, and the spec says so: a one-to-one renaming that keeps each handler and, within each task, the order of its numbers. Every program of the differential whose trace has events of started tasks is also run in both engines under `--virtual-time`, whose output, exit status and whole trace must be equal, so a counter that skips numbers or counts quiet installations still fails. A new conformance case, `started_tasks_install_handlers`, and its native test lock both.
