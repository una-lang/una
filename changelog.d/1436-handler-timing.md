- **Security: the timing label of a deadline counts what a reached handler runs** (#1436). The timing label of a `within`, a `first of`, a `for ever within`, a driven step and a `limiter` installation counted a handler that the code under the deadline can reach only by the deep labels of its parameters and by the operations its `uses` names, with `⊤` for a parameter of function type alone. A parameter that held a function inside a kind, a `List` or an `Option` counted as `public`, and the calls of function values, the calls of functions and the opaque applications in its operation bodies were not counted, so a function the handler was installed with could run a loop of `secret` length inside a `within` and `if error pass` published whether it timed out. A handler now counts by what its operation bodies run, their lambdas and tasks included, taken as the site's own code is, and a parameter whose type holds a function at any depth is `⊤`, whether or not the handler calls it (`spec/26 §2` rule 5 item 3, ADR 0116 IF5 item 3). `L_lim` gives the same `⊤` to such a parameter. A package that ran such a function under a deadline, or that installs a handler holding one where a deadline can reach it, is now rejected with U4001, U4002 or U4003. No example of the repository is affected.
