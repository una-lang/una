- **The release gates pin their Docker backend** (#1082, `docs/release-gates.md` §3). `scripts/release-gates.sh` refuses, before any gate, to run a gate that uses Docker (`linux`, `linux-arm64`, `release`, `reproducible`, `hunt-linux-arm64`) unless `DOCKER_CONTEXT`, or else the active context, is Docker Desktop's `desktop-linux` and `DOCKER_HOST` is unset, so that another container runtime that holds the active context never runs a gate. It exports the context for every gate, and the record names the context and the Docker server's version.
