- **The timing rule of `via` follows function values precisely when none can come from outside** (#1710, `spec/07 §5` rule 7). A `via` that calls or applies a function value now counts only the lambdas written in the code it reaches and the functions it names as values, unless a value can come from outside that code (a function-holding parameter of the `via`, an operation answer, a handler's parameters or value calls, an unchecked function); only then does every lambda count, so a `within` in an unrelated lambda is no longer refused wherever such a policy is called.
