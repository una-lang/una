- **Keyed hashing for the hash tables of edition `0.4`** (#974, ADR 0119 rules 9 and 19). A new crate, `una-hash`, shared by both engines: SipHash-2-4 with its reference vectors, the hash encoding of an `Eq` value, the process key from the operating system's random source through `getrandom` (in the trusted base, `docs/security/tcb.md`) and one key per table, and the ordered hash table with its own index. A new runtime code, U6009, aborts a run when the host gives no random bytes. Its test hooks exist only in test builds, and the release checks look for their marker in the shipped `una` and `libuna_rt.a`; `scripts/release.sh` refuses build flags that set `getrandom_backend`. `spec/28` starts with its section on keyed hashing. No construct is added yet.
