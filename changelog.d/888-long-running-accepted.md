- **Accepted: long-running programs** (#888, ADR 0116). Edition `0.4` will let a package hand its loop to the host with a `[drive]` table and a total `step` function called once per tick, and will gain `for until` with a verified `decreases` measure, `for ever` in functions whose header says `diverges`, `for ever within` a time limit per iteration that cuts only waiting, and `stop`, `stop when` and `skip`. SIGINT, SIGTERM and `--deadline` will make the waiting operations of a `for ever` fail with `Interrupted` and end the loop at its next iteration start, where an `on stop` block cleans up; a grace period bounds the wait (U6007 past it), and a third signal still ends a stuck process. Every value that a deadline can change, including through the program's own tasks that run beside it, will carry a timing label; host stops, as inputs, need none. Nothing is implemented yet.
