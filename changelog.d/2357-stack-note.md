- **A refused stack reservation is said, not silent** (#2357, #2358, from the review of #2355). When the system refuses a thread of the 1,088 MiB stack sized from the Core depth bound, as a limit on virtual memory (`ulimit -v`) or strict overcommit can, `una` writes one note to stderr, `note: the system refused a thread stack of 1088 MiB (...)`, once per process and never under `--json`, and runs on a smaller stack as before. The requirement is in the known limits. A snapshot now pins what `una core --json` writes for a chain of `let`s with a lambda given to an `of` parameter, byte for byte as the recursive writer of v0.5.2 wrote it, and a test pins that the release run builds its tests at opt-level 0 and runs `core_depth` among them every night.
