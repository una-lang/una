- **`std.collections` and `Map.update` in edition `0.4`** (#975, ADR 0119 rules 0, 2, 3, 8, 11, 13 and 18). A package of edition `0.4` can import `std.collections`, which exports the types `Stack`, `Queue`, `Set`, `HashMap`, `HashSet`, `PriorityQueue` and `BitSet` and the record `Ranked`; their operations land with each type. A `Set` item and a priority need `Ord`, a hash key `Eq`; `HashMap`, `HashSet` and `PriorityQueue` have no `==`, with a message that names `same_entries(as:)` or `same_items(as:)`, and still interpolate. A package function named like one of their built-in methods, whose first parameter is that type or a type parameter, is U1002 in `0.4`, and so is an `update` on a `Map`. Maps gain `edit m.update(key:, initial:, change:)`, which calls `change` once and keeps the map when it fails. `spec/28` gains its sections on the module, the types and their equality, and the Una form. Earlier editions do not change.
