- **`F64`, edition 0.3 (preview, ADR 0114, `spec/29`).** IEEE 754 binary64 with one canonical NaN: float literals (`0.5`, `6.674_30e-11`, `1.0e21`), `+ - * /` correctly rounded, division by zero giving infinities or NaN, `==` by identity and `<` by IEEE totalOrder (so `F64` is `Eq` and `Ord`, sorts deterministically and keys a map), the IEEE comparisons as methods, `abs`, `sqrt`, `fma`, `rem`, the roundings, `copy_sign`, `ieee_min`, `ieee_max`, `clamp`, the classifications, `to_bits`, `to_f64()` on integers and `to_int_exact()`, and the prelude functions `nan`, `infinity`, `f64_from_bits`, `parse_f64`, `as_f64` and `json_number`. Rendering writes the shortest text that reads back to the same bits. New codes U2031 (a literal out of range), U2032 (a float pattern), U2033 (a comparison with a literal zero) and U6006 (a floating-point environment that is not the default one, tested before an edition 0.3 package is read). This step runs in the interpreter; native code and the verifier's floating-point encoding follow, and until then a float in a clause is U2014 and `una build` reports a float program as not compiled yet.
