- **Proposed: long-running programs** (#888, ADR 0116, Proposed). Edition `0.4` would let a package hand its loop to the host with a `[drive]` table and a total `step` function called once per tick, and would gain `for until` with a verified `decreases` measure, `for ever` in functions whose header says `diverges`, `for ever within` a time limit per iteration, and `stop`, `stop when` and `skip`. SIGINT, SIGTERM and `--deadline` would make the waiting operations of a `for ever` fail with `Interrupted` and end the loop at its next iteration start, where an `on stop` block cleans up; a grace period would bound the wait (U6007 past it), and a third signal would still end a stuck process. Every value that a deadline can change, including through the program's own tasks that run beside it, would carry a timing label; host stops, as inputs, would need none. Nothing is implemented yet.
