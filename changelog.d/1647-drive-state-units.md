- **The state of a driven module keeps its units of measure** (#1647, `spec/26 §2` rule 2), edition `0.4` preview. The host hands the state of a `drive` module from `init` to `step` and from `init` and `step` to `on_stop` unchanged, and the units of the three types are now compared at every position, at the top, in each type argument and in function types: `init() -> Int of Second` with `step(edit state: Int of Millisecond, input: Tick)` is U2028 at the type of `state`, as the same flow is in ordinary code, where before it checked clean and `una run` took 7 seconds as 7 milliseconds. Core IR has no units, so `una run` and `una build` compare the units the checker recorded as well, and refuse a difference as a usage error, exit code 2. A driven module whose state changes units at a hand-off is now rejected; declare the state with one unit and convert it in the body.
