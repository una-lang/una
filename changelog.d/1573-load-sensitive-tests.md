- **Checking a file with many syntax errors is no longer quadratic, and the tests that failed under load are deterministic** (#1573, ADR 0096 rule 12). The recovery of broken declarations and the repairs of U0101 and U0001 found the declaration or line of each error by a scan, and the renames of names that start with `_` read the whole file again for each error; they now use binary searches and one set of the file's words, O(n log n) in the declarations, lines and errors of a file, with a new scaling test for the renames (one very large declaration with thousands of `_` names is still quadratic in its own size and has its own card). The tests of the solver child's stand-in, the tick and operation waits, the native trace of S-39 under the real clock and the HTTP time-out at a limit no longer depend on the machine's load: a bounded retry keyed to a late handshake only, a latency floor measured beside the waits, a comparison task by task as `spec/27 §8` defines it with whole traces under `--virtual-time`, and a time-out that leaves the first exchange room.
