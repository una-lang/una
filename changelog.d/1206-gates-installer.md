- **The solver's release gates, and an installer that downloads nothing but `una`'s archive** (#1206, ADR 0124 rules 11, 18, 19, 31 and 32, the sixth slice of step 1, `docs/release-gates.md`): the gates `solver-identity` (the solver child against the standalone `z3` built from the same library, byte for byte, and against the Z3 project's release by status), `limits` (memout, cpu and wallclock each end as their reason) and `toolchain-free` (the release `una` alone checks and tests a package under a sandbox that starts no other program, and in a bare container); `scripts/z3-library.sh` gives every gate and `scripts/local-ci.sh` the cached library; `scripts/release.sh` embeds the library whose digest `supply-chain/z3.lock` records for the target and links the C++ runtime statically on Linux; `scripts/check-release.sh` refuses a development build and a build with the solver's test hooks; `install.sh` no longer downloads Z3 and needs no `unzip`.
