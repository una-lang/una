- **The `hunt` gate's oracle sees through redaction** (#794, ADR 0115). A development-only runner, `una-oracle`, runs each variant as `una run --json` does but shows every value and records each declassification; the oracle reads liveness from it and compares each observer up to the releases it sees, so programs whose secret reaches only redacted values, or whose policy releases to `public`, are now tested. It is in no release: `una` is built without its feature, and `scripts/check-release.sh` fails an archive that holds any of it. The gate prints the seconds of each phase and the observed runs' share, and refuses to start when a tool it runs is not an executable for the host. Its time budgets are 335 seconds on macOS and 440 on Linux.
