- **`Set` in edition `0.4`** (#977, ADR 0119 rule 7). `std.collections` exports `empty_set`, and a `Set[T]` has the built-in methods `has`, `edit add`, `edit remove`, `with`, `without`, `first`, `last`, `between`, `items`, `union`, `intersection`, `difference` and `is_subset`, and `.len`. A set lists its items in ascending order and renders as `{1, 2, 3}`. Lookups, updates, `first` and `last` take O(log n); each set operation takes the cheaper of a merge, O(n + m), and lookups of the smaller side's items. Updates of a set held only once happen in place. The items are the set's shape: its top label covers their labels, `has` carries the item's labels, and an item above an editable set's top label is U4001. `add`, `with` and `union` store items with the `refinement` obligations of a refined item type. The interpreter runs sets; the native backend reports them as not supported yet. `spec/28 §6` states the operations, their costs and their labels.
