- **The proof cache key is used only when it is a private regular file of the user** (#1164): the key file is used when it is a regular file, not a symbolic link, with no other hard link, holding 16 to 4096 bytes, owned by the user, and its mode grants nothing to group or others. Any other existing key file now turns the proof cache off (the report's `tcb.proof_cache_key` is `null`) instead of being used. Each of these refusals (a link, not a regular file, another user's file, a mode that grants group or others anything, another hard link, a size outside 16 to 4096 bytes) prints one note on stderr naming the file and the reason, with a hint where one applies (`chmod 600` it for a mode that grants group or others anything); under `--json` stderr stays empty and the report's `null` is the only signal. A missing key file is made, with no note. The proof cache also reads an entry only from a regular file of at most 64 KiB, and never writes through a link at an entry's name.
