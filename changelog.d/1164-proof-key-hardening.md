- **The proof cache key is used only when it is a private regular file of the user** (#1164): the key file, at least 16 bytes, is used when it is a regular file, not a symbolic link, with no other hard link, at most 4 KiB, owned by the user, and its mode grants nothing to group or others. Any other existing key file now turns the proof cache off (the report's `tcb.proof_cache_key` is `null`) instead of being used, and `una` prints a note naming the file; `chmod 600` it to use it again. The proof cache also reads an entry only from a regular file of at most 64 KiB, and never writes through a link at an entry's name.
