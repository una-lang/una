- **`Files`: a missing directory is `NotFound` without a path for the operating system** (#1459, `spec/14 §3` rule 2, security hardening). When the confinement of `Files` finds that an intermediate directory of a path, or the grant prefix, does not exist, it now answers `NotFound` itself (`Io` where a component is not a directory, as before), in `una run` and in native executables, instead of handing the operation the path as the program wrote it, whose links it had not checked; so no operation receives a path other than a canonical directory inside the grant joined with the final component. One value changes: after more symbolic links than the host follows in one lookup (33 on macOS), a path below a missing directory failed with `Io` and now fails with `NotFound`, the value `spec/14 §3` states. A file that does not exist in an existing directory is read (`NotFound`) and created as before.
