- **`Files`: a missing directory is `NotFound`, and the operation gives the operating system no path** (#1459, `spec/14 §3` rule 2, security hardening). When the confinement of `Files` finds that an intermediate directory of a path, or the grant prefix, does not exist, it now answers `NotFound` itself (`Io` where a component is not a directory, as before), in `una run` and in native executables, instead of handing the operation the path as the program wrote it, whose links it had not checked; so no operation receives a path other than a canonical directory inside the grant joined with the final component. The value changes from `Io` to `NotFound`, the value `spec/14 §3` states, wherever the path as written failed as a whole for another reason before the missing directory was reached: more symbolic links than the host follows in one lookup (33 on macOS), or a path as written longer than the host takes (1024 bytes on macOS, 4096 on Linux). No other value changes, and no path moves between success, failure and `Denied`: a file that does not exist in an existing directory is read (`NotFound`) and created as before.
