- **A driven module's functions take no precondition** (#1589, `spec/26 §2`), edition 0.4 preview. A `requires` on `init`, `step` or `on_stop` of the module a `drive` section names, or a refinement at any depth of the type of a parameter or of the result of any of them (at its top, in a type argument such as `Option[Pos]` or `List[Pos]`, or in a function type), written there or carried by a refined kind, is U7008 at the section's `module`, with the clause or the type as the related span. The host calls these functions with no fact it establishes, so the verifier assumed a precondition that nothing proved; the same rule holds for `handle` and `on_stop` of a `serve` module (`spec/31 §7`).
