It reads release artifacts only, built for the check, since a test build unifies the features of dev-dependencies in. It fails closed, runs in `scripts/local-ci.sh` after the tests and in the release gates' `build` gate, and on macOS needs the pinned toolchain's `llvm-tools` component.
