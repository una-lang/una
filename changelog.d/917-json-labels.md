- **`Json` values carry labeled data in edition 0.4** (#917, ADR 0073 J5, amendment of 2026-11-09 accepted on 2026-11-10, `spec/23 §5` rule 2). A constructor of `Json` (`Boolean`, `Number`, `Decimal`, `Str`, `Array`, `Object`) accepts arguments at any label, and its result's top label is the join of every label of its arguments, so a server can echo `internal` request data as an `internal Json` in an `internal` reply, with the structure and escaping of `to_json` and no policy. Reading the value, `to_json`, equality and sinks are raised by that label, so the U4001 or U4003 moves from the constructor to where the labeled value reaches a lower declared type or sink. Editions 0.2 and 0.3 are unchanged.
