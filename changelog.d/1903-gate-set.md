- **The release gates follow the shipped targets** (#1903, #1933, ADR 0124 rule 31). The required gates are those of the gate machine and of each target of `scripts/release-targets.txt`: the emulated `linux` gate is required only when x86_64 ships, a new `limits-linux-arm64` gate runs the limits and confinement cases natively on linux/arm64 (and `limits-linux` for x86_64, refused under emulation), the macOS `limits` gate also runs the confinement cases, `scripts/release-gates.sh` exits with its verdict (1 for FAIL, 3 for INCOMPLETE), and the docs bundle's manifest names the shipped targets (`targets`).
