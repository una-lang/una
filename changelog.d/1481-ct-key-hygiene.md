- **Constant-time and key hygiene in the runtime and the cryptography** (#1481, security, defense in depth, ADR 0133 rules 5, 7 and 8): `==` on two `Hashed` values reads every byte of both in each engine, through one routine, instead of stopping at the first byte that differs, and the native runtime no longer copies the two values to compare them; the mask of the final select of Poly1305 passes the optimization barrier that every other select of `una-crypto` uses; HKDF-Expand wipes its scratch block on every path, the error of a block step included (a path no hash of the crate takes); `Keys.hmac` in a native executable reads the key in the table of the run and the data in the heap, with no copy of either; and the variable-time routines of ECDSA verification and the table-indexed Montgomery exponentiation carry `_vartime` in their names, each use stating why its operands are public, which a test checks. No behavior of a program changes. The scaling test of `una-crypto` (`tests/perf.rs`) no longer times a 32 MiB allocation and copy with each pass.
