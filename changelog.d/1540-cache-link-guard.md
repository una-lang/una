- **The proof cache is off for a run when `.una`, `.una/cache` or `.una/cache/proofs` is a symbolic link** (#1540, the interim of `docs/plan/proof-cache-eviction.md` section 6.4). A link committed at any of the three, dangling or not, leading outside the package or inside it, makes `una` neither read nor write the cache through it; the run solves every query, so its statuses, counterexamples, diagnostics and exit code are those of a run with no cache, and only `obligations.cached` stays 0. Before, a store refused only a link leading outside the package, and reads followed every link. Removing the link brings the cache back.
