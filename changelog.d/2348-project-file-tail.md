- **A FIFO, a device or a directory at `ita.lock` is refused, a growing path-dependency manifest gets the bound's message, and every open of a project file is non-blocking and takes no terminal where the platform allows** (#2348, #2349, #2350, #2392, #2393, #2394, #2395, #2396, #2397, #2398, #2399, `spec/30 §1` rule 4, §9 rule 1; kind: U7008, U7009). `una check` and `una ita verify` said "the package has no ita.lock" when `ita.lock` was a FIFO, a device or a directory; they now refuse it as not a regular file, and a link that names nothing is refused as broken. A path dependency's `ita.una` that grew while it was read was refused as having "changed while it was read"; it is now read through the same capped read as the root's files and refused as holding more than its bound. The opens of `tree` now add `O_NOCTTY` beside `O_NONBLOCK`, and both are known on macOS, on Linux and Android for the architectures with the generic values, and on FreeBSD, DragonFly, NetBSD and OpenBSD; rule 4 states where the guarantee holds. New tests cover a FIFO, a directory and a link to a device at `ita.lock`, through `discover` and the CLI, a manifest appended to while it is read, and a FIFO opened with and without the flags. O(min(n, bound)) to read a file of n bytes, as before. The root package's modules under `src/`, a single-file package, `una.toml` and `verification.lock` were read with a plain read: a FIFO at `src/x.una` made `una check` wait forever, and a link to `/dev/zero` grew its memory without bound. They are now read as the project files are, a regular file checked before and after a non-blocking open, and refused past their bound (#2392). A file that shrinks while it is read is refused as changed, never read as its prefix (#2393). A link at `ita.lock` that names nothing is refused as a broken link instead of reported as a missing lock (#2395). The flags also cover 32-bit RISC-V, and a test pins them to the platform's `O_NONBLOCK | O_NOCTTY` (#2394, #2396). Two links to `.` in `src/` made `una check` walk the package exponentially: the walk of `src/` now reaches each directory once, refusing a link back to one already walked, and lists at most 20,000 entries and 10,000 modules, none deeper than 32 segments (#2397). The 256 MiB bound of §9 rule 1 now holds for a package's manifest and modules together, the root's and a path dependency's, not for each file alone (#2399). The edition of a loose file is read from an enclosing `una.toml` within 256 MiB, as every file of a package is (#2398).
