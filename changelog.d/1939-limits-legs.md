- **The limits legs check what they run** (#1939, ADR 0124 rule 31). `scripts/limits.sh` refuses to run unless the new `scripts/emulation.sh` finds the process native: besides the marker of `scripts/local-ci.sh` and Rosetta on macOS, it now detects on Linux an emulator that runs the shell as a `binfmt_misc` interpreter (Rosetta for Linux, QEMU's user mode), by the ELF machine of the shell's executable. Each of its two runs must pass exactly its count of cases (3 limits cases; 12 confinement cases on macOS, 8 on Linux), held to the test files by a test. `scripts/local-ci.sh --linux` runs the `linux/amd64` container natively, with no emulation marker, when the Docker engine is x86-64, so `limits-linux` can pass on such a host (not yet run on one). `docs/release-gates.md` states in §1 rule 2 that a tag needs every required gate, records the reading of rule 31 and its sign-off for the `linux` gate, and lists the cases of rule 31 that the limits gate does not run yet.
