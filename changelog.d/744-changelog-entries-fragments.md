- **Changelog entries are fragments, assembled at release** (#744, `CONTRIBUTING.md`). A pull request adds one file, `changelog.d/<issue>-<slug>.md`, holding one bullet, and never edits `CHANGELOG.md`, so two pull requests never conflict on the `## Unreleased` lines. The release pull request runs `scripts/changelog-assemble.sh`, which checks every fragment, writes the bullets under `## Unreleased` ordered by issue number and then file name, and removes the fragments; the released sections and their check (#645) are unchanged. The entries that were under `## Unreleased` are now fragments.
