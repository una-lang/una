- **The documents' links are checked without mdBook** (#708). `scripts/site.sh`, which built an mdBook site that nothing published, is replaced by `scripts/doc-links.py`, which keeps its checks on the documents themselves: every link of README.md, the root documents, the charter, the guides, the specification, the release records, the ADRs and the security advisories, an image included, names a file or directory that git tracks (#305), and every `#fragment` to one of those documents now names a heading of it, by the id the website gives that heading. It needs only Python 3 and git, so `scripts/local-ci.sh` runs it on every run, where it skipped the site without mdBook 0.5.4. In the Linux runs it checks the documents on the host before the container, since git cannot list a worktree's files there; the container then runs its self-test, and its document check only when git can read the checkout. The `site` release gate runs it first, and `scripts/site-website.sh` checks that the pinned website gives the documents' headings the same ids. `site/book.toml` and its theme are removed.
