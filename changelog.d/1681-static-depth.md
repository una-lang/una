- **Spec and tests: a lowered `--task-depth` against the static depth of a request task** (#1681, `spec/31 §1`). A request task with no recursion ends alone only when an operator sets `--task-depth` below the longest chain its code shows, and which chain runs is a branch, which data above `internal` cannot decide in a program that starts tasks (`spec/27 §8` rule 5, #1684); `spec/31 §1` now says so instead of calling the case uncovered, and `security/server_start_static_depth_secret` with its `internal` twin pins it.
