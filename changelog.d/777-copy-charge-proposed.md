- **Proposed: the copies of a `together` block, made in sequential phases and checked before each allocation** (#777, ADR 0113, Proposed). Native code would copy a block's inputs and results one task at a time, while none of the block's tasks runs code, and check before each allocation that it fits the memory budget, the copy's working memory included. The budget would stop at U6003 at the block instead of being exceeded, and the native case of #314, whose site varied with how threads were scheduled, would stop at one site. The interpreter does not change.
