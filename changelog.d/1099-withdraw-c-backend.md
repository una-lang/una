- **Withdrawn: the release backend that emits C** (#1099, ADR 0106 amendment of 2026-10-31). No C compiler goes into `una` and no C is emitted into executables (ADR 0124). `una build --release` was never implemented, so no shipped behavior changes. Release builds become Una's own optimizing code generation over Core IR (#1305); the amendment keeps the two build profiles, the rules that no optimization removes or weakens a check and that a wrong proof stays a wrong value, equivalence with the interpreter, the Gate 2 parity targets and the measurement that optimizing backends run checked kernels 6x to 27x faster than Cranelift, and lists the requirements and open questions of the new design. Until then, `una build` (Cranelift) is the native backend.
