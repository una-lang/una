- **The C math library check reads cargo's "nothing to print"** (#1949). The pinned cargo reports a crate that `Cargo.lock` records but the release graph does not hold with `warning: nothing to print.`, an empty tree and exit status 0, which `scripts/no-libm.sh` read as the graph holding num-bigint, num-integer and num-traits, so the check and its canaries failed on every host. The verdict on each `cargo tree -i` run is now `scripts/no-libm-graph.sh`: a tree printed is still a finding, as is any other failure or an empty tree without that warning; only that warning with an empty tree, or a package ID specification that matches no package, is not. `scripts/no-libm-test.sh` gains graph canaries: each kind of result given as files, and the real graph, where `una-core` must be a finding and `num-bigint` must not.
