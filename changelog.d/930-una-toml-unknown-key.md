- **What an invalid `una.toml` keeps** (#930, `spec/13 §7`): the spec and the guide's page for `[package] name` now state the behavior exactly. Only a TOML syntax error gives the default settings, and so edition `0.1`; an unknown table or key, and a value of the wrong type or outside its range, are U7002 and keep that key's default, while every other key, the edition included, is read as written. Two conformance cases pin both sides. No change to the compiler.
