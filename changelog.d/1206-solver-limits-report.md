- **The solver's memory limit, admission and record** (#1206, ADR 0124 rules 6, 10 and 28, `spec/12 §5`, `§9`, `spec/13 §5`, `§6`, the fifth slice of step 1): every command that takes `--solver-wallclock` takes `--solver-memory <MiB>` (256 to 1,048,576, default 4096), the limit of each solver child; the number of children running at once is bounded by the processors and by half the machine's (or the control group's) memory over the per-child limit, so a query's outcome never depends on how many run beside it; the proof cache's key covers the solver library's digest, so caches are verified once again after `una` changes its solver; the report's `tcb` gains `solver_build`, `solver_confinement` and `solver_outer_denied`; ADR 0003 gains the amendment of ADR 0124, and `docs/security/tcb.md` §3.2 records the confined solver.
