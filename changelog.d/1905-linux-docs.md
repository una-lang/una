- **The guides say what Linux on arm64 needs** (#1905, ADR 0124 rule 1). The README, Getting started and the known limits name the targets of 0.4.0, macOS and Linux on arm64 (`scripts/release-targets.txt`), and say that Linux on x86-64 is not a target and Windows is not supported; that the Linux `una` needs glibc 2.39 or later, is dynamic against it with `libstdc++` and `libgcc` linked in, and does not run on musl systems such as Alpine; that `una check`, `una test` and `una run` need no other program while `una build` on Linux links through `cc`, writing an executable dynamic against the glibc of the machine that built it, with no static or musl executable yet; and that the solver refuses root there too. The foreign code inventory lists the GNU C++ runtime linked into the Linux `una`.
