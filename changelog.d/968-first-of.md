- **`first of` races branches** (#968, ADR 0117 rules 4, 6, 10, 12 and 13, IF3, `spec/27 §6`), in edition `0.4`. `let quote = first of` with two or more indented branches runs each branch as a task: the first to return gives the value, and the others are canceled, their frames left by the failure path, and a request they were waiting on ends `interrupted` at once. It fails only when every branch fails, with the lowest-indexed failure. The trace lists the winner's events first, then the other branches' in index order, each canceled one ending with `cancelled`, under the paths `p.f<c>.<i>`. The interpreter, and native code under `--virtual-time`, run the branches in index order up to the first that returns, so both engines agree, ties going to the lowest index. Checks: U2035 for a body with fewer than two branches or a line that is not an expression, U2023 for captures, U2001 for branches of different types, and the timing floor of IF3 over every branch (U4003, U4002), with the value labeled by the timing of every branch and each `first of` above `public` in the report's `timing` list. The report's `out_of_model` list gains "which branch of `first of` wins, beyond its label". A branch's depth is bounded by `--task-depth` below its block.
