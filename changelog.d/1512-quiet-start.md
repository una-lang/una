- **Security (S-40): a `start` under a `secret` branch no longer shows in the trace** (#1512, `spec/26 §6` rule 4, `spec/27 §7` rule 5). Inside a public `tasks` statement, a `start` under a program counter above `public` moved the index `k` of every later `start` of the same statement, so the `task` path `s<c>.<k>` of a later public task's events, and the worker that `k` picks, spelled out the secret, and when the block then failed it added one `cancelled` event per such task. Such a `start` is now quiet: its task, `s<c>.q<k>`, is numbered apart from the statement's public ones and ends without its `cancelled` event, in both engines.
