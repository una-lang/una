- **The `serve` section of `ita.una`, checked** (#1008, ADR 0123 step 6, `spec/31 §7`), edition 0.4 preview. `serve` names the module whose `pub handle(request: internal Request) -> internal Reply` the host calls for each request, with an optional `pub on_stop() -> Unit`, and an optional `within` in milliseconds from 1 to 86,400,000. A missing `module`, a value out of range, an unknown line, a module that is not in the package, and a `serve` section beside a `run entry` or a `drive` section are U7008. A `requires` or a refined parameter or result type on `handle` or `on_stop`, a precondition no call of the host would establish, is U7008, and a section with any problem inside it is not read. The `uses` of `handle` and `on_stop` are checked against the grants, the final grants of `una run` included (U3012); `on_stop` cannot declare `fails` (U3029); neither may say `diverges` (U3027) or use `HttpServer` (U3033: in this form the host owns every exchange). The driver is a hand-off site of `L_srv`, whose preview label is then the top label, so a `within` in the section is U4003 at its value until `L_srv` is computed more precisely. `una report` lists `HttpServer` and each `serve:` grant with its scheme, limits and `Host` check under `tcb.serve_grants`, the server code under `tcb.server`, three server entries at the end of `out_of_model`, and a new `warnings` list (plain `http` off loopback, `hosts=*`, `peer=none`, `peer_buffers=none`, `tls12`), within `una.report/2`. `una run` and `una build` of a package with a `serve` section report the module's shape, then (for `una run`) a missing `serve:` grant, each a usage error before any listener is bound, and otherwise run or build its driver (#1587, #1008, #1782); `una check`, `una test` and `una report` work, and tests call `handle` directly.
