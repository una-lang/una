- **Two more example servers and the `serve` reference page** (#1793, ADR 0123 "Examples"): `examples/orders`, a JSON API whose `serve` section's `handle` reaches its store through a capability, with a handler over `Http` and in-memory handlers for its tests; `examples/proxy`, a rate-limited proxy in the language form, paced by its `serve:` grant (600 a minute), which leaves out the record's per-request `within` and `limiter` that the preview refuses in a server; and `docs/guide/configure/ita/serve.md`, the reference page of the `serve` section.
