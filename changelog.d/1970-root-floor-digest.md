- **A root-version floor of the earlier form takes the digest of its own version** (#1970, security, ADR 0122 amendment of 2026-11-09 L3, `spec/30 §14`): a floor written as the version alone, as release 0.3 writes it, now records the digest of that version's root metadata the first time a command walks and verifies the root chain at that version (`una ita lock`, `una ita fetch`, `una ita unbundle`), so `una check` and the offline loads then refuse a forked root of that version (U7010) instead of comparing by version alone; a floor that holds a digest is never replaced at an equal version, and another digest there is not stored and is reported as a fork.
