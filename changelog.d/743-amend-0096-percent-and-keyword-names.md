- **Accepted, not yet implemented: a description for `%`, and an exact rewrite for declaration keywords used as local names** (#743, ADR 0096, amendment of 2026-10-15). A `%` gets a description that shows both readings, since Una's `mod` is Euclidean and the `%` of other languages truncates, so it gets no edit. A binding inside a function body or a handler operation body named with a keyword that can never appear in a function's scope, such as `op` or `kind`, is renamed to `<word>_value` through its scope, interpolation holes included, with a fresh name. A function's parameters keep the description, since calls name them. Nothing is implemented yet.
