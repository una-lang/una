- **The Linux runs of `scripts/local-ci.sh` from a worktree pass the advisories test** (#715). In the container, a worktree's `.git` links outside the mounted checkout, so `crates/una-cli/tests/advisories.rs` (#649) read no tags and failed. The host now runs the test with the repository's tags before starting the container, and only when it passes does the container's run check the page alone, saying the host checked its releases. Anywhere else, a repository without tags still fails it. `scripts/release-gates.sh` unsets the variable, as it does the released sections' one.
