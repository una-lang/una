- **Repairs that narrow before they widen at module boundaries** (#1397, part of #565, ADR 0093 rule 6, `spec/13 §3`, `§5`). In edition 0.3, a U3020 whose requirement lies within the boundary's ceiling, from a caller that holds a binding permitting it, has the grant `with @x = @y[ops]` narrowed to what the callee declares as its first repair, which `una fix` applies when `@y` is `@x` itself or the only binding that qualifies; when several qualify, the repair is advice that lists them, since which one the boundary receives is a decision about trust. At a function value and at a handler's installation the grant is advice; a requirement the ceiling withholds gets only advice for a handler within the ceiling, naming what it withholds. U3021's repair narrows the grant to the ceiling or says that no grant keeps both. U3001 and U3002 rank a narrowed rebinding of a binding the caller holds first, with an edit only when exactly one binding qualifies, and mark a widening of a public header as an authority change, last. `una fix` applies a boundary edit only as one narrowed U3020 grant, never an edit of U3021 or U3024, and never writes a ceiling. Editions 0.1 and 0.2 keep their repairs.
