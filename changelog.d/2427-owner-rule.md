- **A manifest in a directory owned by another user gives its edition again** (#2427, `spec/30 §1` rule 4; refs #2419, #2420). The search for the manifest above a loose file stopped at the first directory, or manifest, owned by a user other than this one and the superuser. In a container whose checkout belongs to the runner's uid while the tests run as another user, every loose file and package fell back to edition 0.1, and Linux CI failed. The search now reads no owner. It still stops at a world-writable directory such as `/tmp`, an error other than "not found" at a manifest's path is still refused, and so is a manifest that does not read.
