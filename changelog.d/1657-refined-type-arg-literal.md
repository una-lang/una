- **A list literal given for a field of a generic kind takes the type the expected type fixes** (#1657, ADR 0103 rules 3 and 5, `spec/18 §2` rule 1). `Box(v: [5])` where a `Box[List[Pos]]` is expected, with `kind Pos = Int where it > 0`, was U5001: the literal was typed `List[Int]`, so its flow into the field `List[Pos]` asked of a fresh element with no facts, which is refuted. A list literal now takes the field's type at the expected type arguments, as an integer literal and a constructor already did, also for a field of type `List[T]` and inside `Some`, so each element is its own obligation: `Box(v: [5])` is proven and `Box(v: [0])` stays U5001. For the same reason `Box(v: [1, 2])` where a `Box[List[U8]]` is expected is accepted, as `spec/18 §2` rule 1 says, where it was U2001.
