- **The standard library reference describes the host capabilities and their operations** (#903, part 3c of #853). `docs/std/reference.json` gains `Console`, `Clock`, `Env`, `Files`, `Keys` and `Http` with a new `operations` field: each operation's parameters, result, failures, the label it accepts and the narrowest grant spec that gives it. It also gains `FileError`, `HttpError`, `Header`, `Response` and `std.testing` `fake_hash`, each with an example under `docs/std/examples/`. The test of the reference checks each operation against its declaration, and asks the checker, in a probe package per grant spec and operation, that the operation needs a grant, that its grant gives it, and that no other grant spec that gives it gives less.
