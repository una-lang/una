- **Counterexamples with a value of a sum kind** (#855, `spec/12 §5`, `§7`, `spec/13 §6`): the solver script declares every symbol of the requested terms together with the query's own, so a shown value of a sum kind that no assertion mentions no longer makes the model unreadable; and when the solver gives no values, the human note is the fixed `counterexample: not available (the solver gave no values for the model)`, with the solver's message, which names internal symbols, kept in the `--json` document only.
