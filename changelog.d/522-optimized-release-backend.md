- **Accepted: an optimized release backend that emits C** (#522, ADR 0106). `una build --release` will emit C in a subset with no undefined behavior and compile it with the system C compiler, keeping every check and the interpreter's meaning, with three new release gates; Cranelift stays the default. Measured on checked kernels, the optimizing route runs 6x to 27x faster than Cranelift (`docs/adr/evidence/0106/`).
