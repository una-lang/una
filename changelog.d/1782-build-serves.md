- **`una build` serves** (#1782, ADR 0123, `spec/31 §1` rule 10 and §7 rule 5), edition 0.4 preview. `una build` of a program whose `main`, or a driven module's `init`, `step` or `on_stop`, uses `HttpServer`, and of a package with a `serve` section, now makes a native executable, with no test flag. The executable checks its grants before `main`, starts the serve threads, writes the same `serving on ...` line per address as `una run`, and drains at SIGINT or SIGTERM with exit code 0 when `una run` would. What stays closed: a `within` in the `serve` section is still U4003, and `una build` still refuses one; an `https` grant is still refused before `main` by the executable as by `una run`; the scripted connections of `--serve-script` still run only in the toolchain's own tests. `scripts/check-release.sh` now serves `examples/health` with the executable the packed `una` builds as well as with `una run`.
