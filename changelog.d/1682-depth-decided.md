- **IF6's depth rule refuses only tasks whose calls labeled data decide** (#1682, `spec/31 §1`, ADR 0123 IF6). A request task that can recurse and holds data above `internal` is now refused only when data above `internal` decide one of the calls it can make, when every call it can make lies in code the checker records with its labels; with a function value, a handler's operation, a `via` or unseen code in its reach, the coarse test of #1674 stays. A task that recurses on the request's length and holds a `secret` key that decides none of its calls is accepted, live in both engines.
