- **`una build` with a release archive on macOS arm64** (#1833, ADR 0124 rules 12 and 25). The release runtime is stripped with Apple's `strip -S`, which rewrites each object through `ld -r`: `__TEXT,__eh_frame` becomes S_REGULAR and each FDE's CIE pointer a SUBTRACTOR/UNSIGNED pair of two local symbols of the section. The internal linker refused the section (U8001), so `una build` failed with every packed `una`. It now knows `__TEXT,__eh_frame` by its name, as ld64 does, and reads a CIE pointer pair, which must name two local symbols of the section; any other relocation there stays U8001. The oracle test links a release-built Rust program that unwinds after `xcrun strip -S`, against Apple's `ld`.
