- **The two-run oracle over servers** (#1011, ADR 0123 S9). A mode of the security hunt's oracle runs servers over their scripts of connections and compares, at `internal`, every byte their peers receive, since `reply` accepts `internal`. Family N6's request tasks read a secret balance and keep it from the reply, release it through a policy, or miss its label (closed calls a correct checker rejects); `hunt servers` runs them through must-reject and that oracle, with a canary that must leak on the wire alone. The release gate's fixed run is unchanged.
