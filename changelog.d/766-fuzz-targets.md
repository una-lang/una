- **The `sanitize` release gate fuzzes the native runtime** (#766). Three libFuzzer targets in `fuzz/`, a crate outside the workspace with its own lock, run under AddressSanitizer: `literal` (the entry points that read bytes by pointer and length), `words` (sequences of calls of the entry points on words the generated code never passes) and `json` (the runtime's JSON parser, whose canonical text must parse back to itself and agree with the entry points). Each runs a fixed number of inputs from committed seeds with a fixed seed, after a canary target whose planted crash must be found and minimized; a crash prints where its input and the minimized input are kept. No fuzzing tool is installed: the gate builds the crate with the checking toolchain and states its flags. The `deps` gate covers `fuzz/Cargo.lock` too, with cargo-deny and the review record `supply-chain/fuzz-crates.tsv`.
