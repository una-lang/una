- **Security: a same-size checkpoint under another root version is recorded as evidence** (#1538, `spec/30 §11` rule 9). When the registry client proves a lock's point that names an older root version a prefix of the latest checkpoint, and the latest checkpoint, signed under the last root version, is of the point's own size, the two are checkpoints of one size naming different versions: still refused (U7010), and now, when the log signed both, recorded as typed evidence against the registry with the two versions and the places read, and said so by `una ita lock --check`, `una ita fetch` and `una ita bundle`. A point the log did not sign is refused alone, with no evidence recorded.
