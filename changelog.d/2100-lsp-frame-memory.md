- **The language server bounds the memory of a parsed frame and reports a refused one** (#2100, security, ADR 0063 rule 2): a body within the 64 MiB limit could still make `una lsp` hold about 100 times its size once parsed (`[{"":0},{"":0},...]` of 64 MiB made more than 6 GiB of values). A body is now refused, before any value is made, when it is nested deeper than 127 arrays and objects or has more than 131,072 values (elements and members); one frame then holds at most 320 MiB while it is parsed and 128 MiB after. A refused frame is no longer silent: one line on stderr and a `window/showMessage` notification name the limit. A frame past the depth or the value bound is dropped and the session goes on; a header or a `Content-Length` past its bound, a body that is not JSON and a body cut short end `una lsp` with exit code 2, where it used to end with 0. Real editors are not affected: their largest structured message, `initialize`, has a few thousand values.
