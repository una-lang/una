- **Module constants in edition `0.5`** (#1632, ADR 0126; a construct the edition `0.5` preview adds). A module of a package of edition `0.5` declares a named value at the top level, `[pub] const name: type = value`, with its type required (U0101 at `=` without it), exports it with `pub` and imports it by name; a top-level `let`, U7007 there, is read as `const`. The value is a constant expression: literals, `-`, the integer, `F64` and decimal operators of ADR 0126 rule 3, `and`, `or`, `not`, comparisons, constructors, lists, parentheses and other constants, declared before or after. The compiler evaluates each value once, at check time, in dependency order, and substitutes it at every reference, so `una core`, the verifier, the interpreter and native code see the literal; a contract that names a constant is proven with its value, and a refined constant type gives one `refinement` obligation at the value with a closed goal (U5001 without a counterexample note when refuted). New codes: U1011, a constant that depends on itself, once per cycle; U2041, a value outside the constant expressions (naming the construct), a division by zero, a value that does not fit its fixed-width type, a value past the caps (4,300 digits, 1,000,000 elements, fields and characters), or a declared type that holds a function type. A capability reference as a value is U3005; an assignment to a constant and an `edit` of one are U2019, a `take` of one U2020. `std.time` declares `millisecond`, `second` and `minute` as `pub const` constants of `Int of Millisecond` in edition `0.5`, with the same values; edition `0.4` keeps its built-in names. The edition ledger gains `module constants`, and `una report` counts them. Editions `0.1` to `0.4` do not change. Costs: the dependency order and the cycles are O(constants + references); each value is evaluated once in O(its size) under the caps; a scalar reference costs what a literal costs.
