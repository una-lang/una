- **The standard library reference: numbers, lists, options and results, maps** (#853). `docs/std/reference.json` now describes `Nat`, `abs`, `min` and `max` in a Numbers area; the list functions; `Option`, `Result` and their functions; `Entry`, `empty_map` and the map methods, with the edition 0.3 rules for refined keys and values; and `.len`. Each has a checked example. Entries say how an edition 0.1 declaration differs (`describes`, `earlier`, which quotes each line where the declarations differ), whose effects and failures a function has (`effects_of`), a method's receivers, and a kind's fields or definition. Costs stated in a sentence rather than a table are given too: O(log n) for map lookups and in-place updates, O(1) for `set` on a list and amortized O(1) for `append`. Every prose text follows the rules of doc comments. Where a list function and a map method share a name (`set`), the checker, not the types written in the example, decides which one each example calls.
