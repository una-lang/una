- **The standard library reference: numbers, lists, options and results, maps** (#853). `docs/std/reference.json` now describes `Nat`, `abs`, `min` and `max` in a Numbers area; the list functions; `Option`, `Result` and their functions; `Entry`, `empty_map` and the map methods; and `.len`. Each has a checked example. Entries say how an edition 0.1 declaration differs (`describes`, `earlier`), whose effects a function has (`effects_of`), a method's receivers, and a kind's fields or definition. A method call in an example counts only when it cannot be another item of the same name, such as `set` on a list and on a map.
