- **Security (S-45): a run's trace renders each operation's outcome at its label** (#1552, `spec/11 §5`, proposed amendment of ADR 0032, backport of #1562). The trace redacted an operation's `ok` value by its result's label but wrote whether it failed, its variant and its payload in clear, though the checker labels those decisions (ADR 0085). So the outcomes of public `Files.read`s spelled out the `internal` path of an earlier `Files.write`, which the same trace showed as `<redacted:internal>`, a write's own outcome told which path it took, and an `Http` failure variant told whether an `internal` URL lay inside the grant, in both engines and in editions `0.1` to `0.3`. In a run, an outcome whose label, the decision's joined with its failure type's and its result's, is above `public` is now `{"kind":"redacted","level":"internal"}`, with no text built from the value, in both engines and every edition; Core IR, `--dump-core`, `una --json core` (key `outcome`, additive in `una.core/1`) and the native description carry the label, and a native description without it fails to load. Nothing stops compiling. The cost is observability: in a run's trace the outcomes of every `Http` request, `Files.read`, `Env.get`, `Keys.hmac` and `Files` operation of a package whose file-state label is above `public` are redacted. An example's trace keeps its outcomes in clear. Readers of trace outcomes must accept the kind `redacted`. Not changed: an operation under a branch on an `internal` value still appends its event, so which events appear, how many, and the `seq` of later events can still depend on that value; the fix covers what an event shows, not whether it occurs. Rebuild: there is no version handshake between the compiler and the runtime, so a native executable built before the fix keeps the old behavior until it is rebuilt, a patched `una` linked with an older `libuna_rt.a` still writes outcomes in clear, and an older `una` with the patched runtime exits 3; rebuild native executables with the patched toolchain, `una` and its runtime together.
