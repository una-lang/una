- **Install: a macOS archive downloaded in a browser, and an uninstall that removes the proof cache key** (#2097). The README, the Getting started guide and the known limits say that the installer is the supported way to install, and that the `una` of a macOS archive downloaded in a browser, which is ad hoc signed and not notarized, carries the `com.apple.quarantine` attribute and is killed by macOS when it starts (exit code 137, no output), with the remedy: the installer, or `xattr -d com.apple.quarantine <file>` on the unpacked `una`. `sh install.sh --uninstall` now also removes `~/.una/proof-cache.key`, which `una` makes at run time, and then `~/.una` when it is empty; it removes a key that is a symbolic link without touching the file the link names, keeps a key file that `UNA_PROOF_KEY` names and every file it did not make, and its message says what it removed and names what is left.
