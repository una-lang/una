- **Timing labels: a lambda written at the site is the site's own code** (#1023, ADR 0116 IF5 item 4, `spec/26 §2` rule 5 and `§7` rule 5), edition `0.4` preview. A driven `step`, a `for ever within` body or a `within` that calls `map`, `filter`, `first_where` or `fold` with a lambda written at the call, or calls a name that a `let` of the site bound to a lambda written there, no longer gets the top timing label for it: the lambda's captures, calls and operations count as the site's own code, so a `step` that maps over `public` data with such a lambda needs no label on its `input`. A function value whose code is not known at the call (a parameter, a field, a `uses of` parameter, a local bound outside the site, or any other argument of a prelude function's function parameter) still makes the label top. The rule only accepts more programs, as the preview allows.
