- **The `HttpServer` capability, checked** (#1007, ADR 0123 step 5, `spec/31 §1`), edition 0.4 preview. `std.host` declares `HttpServer` with `next`, `reply` and `close`, the kinds `Method`, `Param`, `Request`, `Exchange`, `Status`, `Reply` and `ServeError`, and the opaque type `ReplyRight`, which only an import brings into scope; in earlier editions an import of them is U1001. The decoded query of a request is the field `params`, since `query` is a reserved word. A `Reply`'s status is refined to 200 to 599 (U5001); its fields are `internal`, so a `secret` body is U4001; `reply` accepts `internal`, `next` accepts `internal` and `close` accepts `public` (U4003), and the failure of `reply` is `internal` (U4002 for `if error pass`). New U3033: an operation of `HttpServer` in a branch of `together`, the body of a `together for` or a branch of `first of`, performed there or reachable through a call, a function value, a handler installed or an operation whose handler can perform one. A `start` whose captures can hold a reply right is checked as the host's answer for its task (IF6, U4003). In a package that performs an operation of `HttpServer`, the label `L_srv` of the serve threads joins every timing site, at least `internal`, with the preview's terms. The operations run in both engines (#1571), and `una run` and `una build` serve a program whose entry uses `HttpServer` (#1008, #1782); `una check` checks such a program and `una test` runs tests with a `given` handler of `HttpServer`.
