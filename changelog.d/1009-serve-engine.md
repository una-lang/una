- **The scripted engine behind `--serve-script` and `--serve-out` in the toolchain's test builds** (#1009, ADR 0123 rule 21, `spec/31 §8` rule 6): with `UNA_TEST_RUN_SERVER=1`, `una run` and executables of test builds serve a checked script in place of listeners and write what each connection received, the same bytes, output and trace in both engines; every other run with `--serve-script` is a usage error.
