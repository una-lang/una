- **`una fix` renames a reserved word only where the renamed program parses** (#836): the U0103 rename of a word reserved for a later version, such as `edit` in `let edit total = 0` of edition 0.1, wrote `let the_edit total = 0`, which does not parse. The rename is now offered only where the program with it parses; where the word stands as the keyword of its later construct (`let edit x`, `edit x`, `take x`, a `together` block), the U0103 stays with no edit, and `una fix` leaves the file as it was. Where the word names something, the rename is unchanged.
