- **The formal re-check refuses ADR 0123's server by name** (#1012, ADR 0123 S10, `spec/31 §9`). F1 does not model `next` as an input stream, `reply` as an effect or the reply rights of `HttpServer` yet, so the re-check reports a declaration whose Core holds a `ReplyRight`, a kind of the server (`Method`, `Param`, `Request`, `Exchange`, `Reply`, `ServeError`), or an operation, a grant or a handler of `HttpServer`, and what reaches it, as not re-checked, never accepted, with the reason "F1 restriction (..., ADR 0123)". The importer read `Request`, `Reply` and `Param` as records of the program before, so a declaration that built a `Reply` or read a `Param`, and what called it, could be accepted; it is now not re-checked. Every other such declaration was already not re-checked, as a form the importer did not read; the reason now names ADR 0123. `formal/UnaFormal/F1/ServerImportTests.lean` pins the verdicts on `una`'s own export, a program's own kind named `Request` read as a record included.
