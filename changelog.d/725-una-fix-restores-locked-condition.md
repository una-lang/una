- **`una fix` restores a locked condition** (#725, ADR 0092 and ADR 0084, amendments of 2026-10-15). When a locked public function's header is weaker than its `[contracts]` entry, the first repair of the refuted `contract_lock` obligation (U3023) now carries an edit that writes the locked condition back on the header's operation, `op where C_lock`, or `op where (C_src) and (C_lock)` when the header already writes a condition, and `una fix` applies it in its tier-1 rounds. The edit only adds a condition and never changes `una.toml`. It is given only when the header lists the operation by name, the lock's condition is on one line and both conditions are within the encoding, and it is withheld while any obligation of the package is unknown.
