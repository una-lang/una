- **`example` is an ordinary name in edition 0.4** (#1584, ADR 0105 amendment of 2026-11-05, `spec/01 §5`). In edition 0.4 `example` is neither a keyword nor reserved: it names a function, a parameter, a local, a field or a module path segment, and a line `example "..."` at column 1 is an ordinary syntax error (U0101) with no U0103 and no rewrite. The test declaration is written `test`, as in edition 0.3. `una fix` rewrites `example` to `test` in edition 0.3 packages only, the migration from editions 0.1 and 0.2, which keep `example` as their declaration keyword unchanged. Edition `0.4` preview: an edition 0.4 package that still writes an `example` declaration now gets U0101 at its text literal in place of U0103; migrate it on edition 0.3 with `una fix`, or write `test`.
