- **`una run --cost-clock`** (#973, ADR 0117 step 7, `spec/27 §8` rule 6). With `--virtual-time`, each check point of the interpreter, each call, operation and loop iteration, moves the virtual clock by one millisecond, so deadlines, refills and `Clock.now` follow the run's work: the clock of the security hunt's timing oracle, where a missing timing label shows as a difference of values. Without `--virtual-time` it is a usage error.
