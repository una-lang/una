- **Accepted: the test declaration is written `test` in edition `0.3`** (#740, ADR 0105). An edition `0.3` package will write `test "name"` where editions `0.1` and `0.2` write `example "name"`, with the same body and rules. `test` will be a reserved keyword in edition `0.3`. An `example` declaration there will be U0103, with an exact rewrite to `test` that `una fix` applies. `una test` will print "test" and "tests" for such a package, and its `--json` the schema `una.test/2`, with the key `tests`. Editions `0.1` and `0.2`, `una.test/1` and Core IR do not change. Nothing is implemented yet.
