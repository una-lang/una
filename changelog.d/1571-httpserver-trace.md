- **The reduced trace form of `HttpServer`** (#1571, ADR 0123 rule 1, `spec/31 §1` rule 7), edition 0.4 preview, not yet reachable by `una run` or `una build`. The events of `next`, `reply` and `close` of the host's `HttpServer` are redacted by their labels, as every event's are, and beneath that redaction are written in the reduced form whatever their labels, in both engines through one implementation: the values of the headers `authorization`, `proxy-authorization`, `cookie`, `set-cookie`, `x-api-key` and `x-auth-token`, in any letter case, as `<credential>`; bodies, and the values of query parameters in `params` and in `target`, as `{"length": n, "hmac": "<hex>"}`, an HMAC-SHA-256 under a key of the run that is all zeros under a script of connections; a reply right as `<reply-right>`. A `reply` whose `Reply` is built from `public` data is now written `Reply(status: <redacted:internal>, headers: <redacted:internal>, body: <redacted:internal>)` instead of `<redacted:internal>`, since every field of `Reply` is `internal`. The runs of `tests/serve_runs/` compare the reduced form of both engines byte for byte, with the redaction of labels lifted by the scripted engine of the toolchain's own tests only, and check that no credential or body reaches a trace. The test build of the runtime with its serve hook is now built in a target directory of its own, so the plain `libuna_rt.a` that other tests link is never replaced.
