- **`una run` of a server installs its stop handlers before it names its addresses** (#1920, ADR 0116 rule 18, `spec/31 §6` rule 14). The interpreter wrote the `serving on` lines and started the serve threads before it installed the handlers of SIGINT and SIGTERM, so a SIGTERM sent once those lines appeared could end the run by the signal's default action, with no drain; it now installs them first, as the executable does.
