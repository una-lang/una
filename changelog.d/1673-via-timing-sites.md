- **Soundness: a deadline or race outcome reaches the result of a `via` function only with a public concurrent label** (#1673, ADR 0098 amendment of 2026-11-06, `spec/07 §5` rule 7). No label is checked in a `via` body, so a `within`, `first of` or `for ever within` there, or in code it calls, a lambda written there included, whose outcome became the policy's result released the timing of the tasks running beside the policy call. Each such site, and each statement a `limiter` installation scopes over, is now U4001 when its concurrent label, the preview's `τ_conc`, is above `public`: programs that call such a policy in a part of a task construct are refused, and the same policy called from sequential code stays accepted, unless the `via` calls a function value or applies one whose code is not known at the call: every lambda's code then counts as reached, so its timing sites are refused wherever the policy is called. One search of the call graph from every `via` function, O(V + E), then O(log n) per site, and a scan of the diagnostics so far for each site it refuses.
