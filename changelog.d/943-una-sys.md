- **`una-sys`, the crate of the runtime's unsafe code** (#943, ADR 0116 rule 18 and Appendix A). It holds the attention words that check points read and the handlers of SIGINT and SIGTERM, which record a host stop with atomic adds, wake waiting threads through a non-blocking pipe, and at the third request restore the default actions; nothing uses them yet. It reaches the operating system through the `libc` crate, Rust bindings only, allowed for `una-sys` alone.
