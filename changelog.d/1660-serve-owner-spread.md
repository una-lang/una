- **Timing oracle for the placement of connections** (#1660, ADR 0123 S4 design §11.5, SC1). The release timing oracle `serve_owner_spread` checks that connections from crafted source ports, all multiples of 8, are served over 8 serve threads like connections from ports as they come, so that placement is keyed; that set-up code before a run's first server operation does not change it; and, as a positive control, that the same connections on one serve thread are measurably slower.
