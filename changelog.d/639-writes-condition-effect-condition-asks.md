- **`una fix` writes the condition that an effect condition asks of a callee** (#639, ADR 0092 and ADR 0084, amendments of 2026-10-14). A refuted `effect_condition` obligation at a call or a `with` now carries an edit as its first repair: the caller's condition, with each of its parameters replaced by the parameter it is passed to, written on the callee's or handler's operation, or conjoined with the condition already there in parentheses. It is offered only for a private function or handler of the same module that lists the operation by name and is never used as a value, when each parameter of the condition is passed as itself and is not an `edit` parameter, its names resolve alike in the callee, both conditions are within the verifier's encoding, and its conjuncts are not all written already. `una fix` checks tier 1 in each round whose tier-0 check is clean, never with `--tier 0`, and applies these edits from refuted obligations only. While any obligation of the package is unknown, no such edit is given, and the repair says why, so solver timing can only stop the rounds earlier. The edit adds a condition and removes none; the guard and `requires` repairs keep a description only. `spec/05 §3` and `spec/13 §5` state it.
