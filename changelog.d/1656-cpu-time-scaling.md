- **Ten scaling tests measure processor time and run beside the others** (#1656). The collection, text, list and JSON scaling tests of `una run` and of native executables that took the longest in the gate time the run of `una` or of the built executable by the user and system time of the children the test waited for (`getrusage(RUSAGE_CHILDREN)`, read in `una-sys`), not the wall clock, so other tests running beside them no longer move the measure. Each holds `cpu_time` in its name, which the timing pattern of `.config/nextest.toml` leaves out, so it no longer reserves every slot. Sizes, bounds and retries are unchanged.
