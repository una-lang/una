- **The release gates read the privacy pattern from the Keychain, and stop without it** (#717, `docs/release-gates.md`). `scripts/release-gates.sh` takes `UNA_PRIVACY_PATTERN` from the macOS Keychain item `una-privacy-pattern` when the variable is not set, never exporting it to a gate, printing, logging or writing it, and stops before any gate when neither exists, unless `UNA_GATES_UNCHECKED=1` asks for an unpublished run. `scripts/release-summary.py` passes the pattern to `grep` through a pipe, never on a command line.
