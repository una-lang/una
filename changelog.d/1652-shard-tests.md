The five tests that looped over a whole corpus run one test per case: `case::<name>` for each conformance case, `interpreter::<name>` and `linkers::<name>` for each runnable program of the native differential, `determinism::<name>` for each target of the determinism test and `core_ir::<name>` for each case of the Core IR export test, so `cargo nextest` spreads them over all cores. The lists are generated at build time from the corpus by the dev-only crate `una-test-cases`, and a test of each file fails when its list differs from the cases on disk. No case is dropped and no assertion is relaxed.
