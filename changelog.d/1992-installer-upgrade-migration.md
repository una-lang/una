- **An installation over an earlier one removes what the new release does not hold** (#1992, ADR 0124 rule 32): run over an earlier installation, `install.sh` removes the files of the earlier record that the new installation does not hold, such as the `bin/z3` link and `z3/bin/z3` of a release before 0.4.0, the `lib/libuna_rt.a` of one before ADR 0124 step 2 and a guide a later release dropped, then the directories of that record left empty, and names them. Every path of the earlier record is checked before anything is downloaded, as uninstall checks it, and for every user, not only root, a path with a `.` or empty component or with a directory on the way that is a symbolic link is refused (a recorded file may itself be a link, which is removed without what it names). Upgrading from v0.3.16 and then uninstalling leaves nothing in `~/.una`.
