- **The release gates undo the clone's release tag** (#1017). The `release` and `reproducible` gates of `scripts/release-gates.sh` make the tag `v<version>` in their clone for `scripts/local-release.sh` and now undo it when the gate ends, however it ends (a tag the clone had from its source is put back), so a later `mac`, `linux` or `linux-arm64` run on the same `OUT`, in a run split into groups, no longer sees the version as released; a tag left by a killed run is undone before the next run's first gate. `scripts/release-gates-tag.sh` changes only the clone that the `clone` gate made under `OUT`, checked by a marker, never another repository or the remote, and `scripts/release-gates-tag-test.sh` checks it on temporary repositories.
