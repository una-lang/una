- **The installer never writes into an existing file, and its TMPDIR guards are tested** (#1966, from the review of #1965): each file the installer writes (`bin/una.new`, `lib/libuna_rt.a`, `README.md`, `LICENSE`, the guides, the record) is written as a new one after its name is removed, so a target that is a hard link to another file, as root possibly outside `UNA_HOME`, no longer has that file written through. As root, the TMPDIR check now runs just before the work directory is made, so `--uninstall`, which makes none, no longer refuses an unsafe TMPDIR. An `id -u` that prints root's id with leading zeros is taken as root. The archive's digest is read from its bytes on stdin, so a TMPDIR whose name holds a newline no longer gives a false SHA-256 mismatch. New tests cover the default TMPDIR as root, a work directory made in the checked physical path and never through a link, and a target that is a directory or a FIFO.
