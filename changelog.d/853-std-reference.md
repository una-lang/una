- **The standard library reference, its first area** (#853). `docs/std/reference.json` describes each item of the Text area: what each parameter means, what it returns, its preconditions, when each failure happens, the variants of `ParseError`, what to use instead and from which edition, related items, its cost where ADR 0070 states it with each term defined, and an example in `docs/std/examples/`. `crates/una-cli/tests/std_listing.rs` checks it against every edition's declarations and ADR 0070's table, runs every example, and requires each example to stop checking once its item is renamed; the other items, built-in methods included, are listed as pending.
