- **A `deps` release gate audits the dependencies** (#770). `scripts/deps-audit.sh` runs `cargo-deny`, at the version that `supply-chain/tools.lock` pins, against the RustSec advisory database fetched for the run: advisories with none ignored, licenses, bans and sources, crates.io only (`deny.toml`). The database's commit goes into the record and the public summary. `supply-chain/crates.tsv` records every crates.io package of `Cargo.lock` by name, version and checksum, and `crates/una-cli/tests/dependencies.rs` fails on a package it does not list, so a new or moved dependency needs a reviewed change; the packages with no source must be exactly the workspace's members. An advisory database more than 7 days old fails the gate. A missing tool, a mismatched version or an advisory database that cannot be fetched fails the gate.
