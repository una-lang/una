- **The exact repair of U0101 for `if c then` at the end of a line keeps an `else if` chain** (#935, ADR 0096 rule 3). When the `else` line continues the chain with `else if d` and blocks of its own, the edit no longer turns that line into an unindented branch under a bare `else`: the chain stays at the `if`'s indentation, each branch with its block, and a `then` that ends an `else if` line goes with the same edit, so the repaired range parses, as an exact edit must (`spec/13 §5`).
