- **Counterexamples show a sum value reached through a record field** (#902). When a refuted obligation's counterexample showed a value of a sum kind whose tag no assertion of the query used, for example a record's field passed to a function with no `ensures`, the model query named the tag's function undeclared, and the counterexample was "not available" with a solver error. The query now declares such a tag, with its range, which every model already satisfies, so the verdict is unchanged and the value shows by its variant.
