- **The re-check's refusal of the server is kept in step with the checker** (#1012, `spec/31 §9`). A test of `una-check` fails when the formal importer's lists of the server's names differ from the checker's (`SERVER_CORE_KINDS`, `STD_TESTING_SERVER_NAMES`) or when a name of the server is neither refused nor exempt, so a kind ADR 0123 adds is never read as a record of the program. The importer also refuses `std.testing`'s `TestRequestError`, `test_request` and `test_exchange` by their module: a declaration that held one was already not re-checked, as a form the importer did not read, and the reason now names ADR 0123.
