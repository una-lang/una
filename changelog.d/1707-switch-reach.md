- **The task-switch rule leaves out code no run reaches** (#1707, `spec/27 §8` rule 5). A check point that data above `internal` decide is refused only in code a run of the program can reach from its `pub` functions, predicates, policies, `via`s, function values, handlers, lambdas and code outside functions; a private function that only `test` declarations call, which `una test` runs and a run never does, is no longer refused.
