- **U3013 advises the form that resolves it where the call stands** (#837, `spec/04 §4`, `spec/17 §3` rule 5). The advice to bind the result with `let` first stays where it resolves the diagnostic. Under a nested `attempt` the advice binds the whole `attempt`, wherever the call stands; in a lambda body, which holds no `let`, it names a named function; in the value of `if error use` or `if none use`, a branch of `if ... then ... else`, the right operand of `and`, `or` and `implies` and a one-line arm of `when`, where a `let` before the statement would run the call every time, it names a form that keeps the call conditional; in a `together` branch it names a function called from the branch's `let`; a call with `edit` or `take` under `attempt` is told to drop the `attempt` and use `if error`; and on a `do` line it names a function that edits a local copy. A call with `edit` or `take` that also has effects is now one U3013, not two with different advice. `una explain U3013` lists the cases. The code and the first part of the message do not change.
