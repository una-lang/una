- **U3013 advises the form that resolves it where the call stands** (#837, `spec/04 §4`, `spec/17 §3` rule 5). The advice to bind the result with `let` first stays where it resolves the diagnostic. Under a nested `attempt` the advice binds the whole `attempt`; in a lambda body, which holds no `let`, it names the whole body or a named function; in the value of a handling clause, a branch of `if ... then ... else` and the right operand of `and`, `or` and `implies`, where a `let` before the statement would run the call every time, it names a form that keeps the call conditional; a call with `edit` or `take` under `attempt` is told to stand alone with `if error`; and on a `do` line it names a function that edits a local copy. `una explain U3013` lists the cases. The code and the first part of the message do not change.
