- **No unused system library in `una` or in a native executable** (#1103). On macOS, `una` no longer carries a load command for `/usr/lib/libiconv.2.dylib`, which the libc crate's link directive added although no code calls iconv: `una` is linked with `-Wl,-dead_strip_dylibs`, and `una build` passes the same flag on macOS and `-Wl,--as-needed` before its system libraries on Linux. `scripts/load-commands.sh` checks the release `una` and a program it links in `scripts/local-ci.sh` and in the `build` release gate, and fails on any load command, dylib, `NEEDED` entry or interpreter that `scripts/load-commands.txt` does not list.
