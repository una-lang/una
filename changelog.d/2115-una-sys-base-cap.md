- **The base code of `una-sys` has a restated cap, and a test now enforces it** (#2115): the base code (the `unsafe`-bearing code outside the feature `solver`) had grown to 1,651 lines, past the 1,594 lines of ADR 0058, with no amendment and no check. A dated amendment of ADR 0058 (2026-11-19) records the breach and the pull requests behind it and restates the cap at 1,733 lines: the 1,651 on `main` plus at most 5 percent. The new test `crates/una-sys/tests/base_size.rs` fails when the count passes the cap, and refuses a `#[path]` or `include!` in the counted files, a build script, and a `solver` module compiled without its feature. No code of the crate changes.
