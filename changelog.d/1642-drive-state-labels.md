- **The state of a driven module keeps its labels** (#1642, `spec/26 §2` rule 2). The host hands the state of a `drive` module from `init` to `step` and from `init` and `step` to `on_stop`, and that hand-off is now a flow into the parameter's declared type, checked at every position of the type: `init() -> secret Int` with `step(edit count: Int, input: Tick)` is U4001 at the type of `count`, where before it checked clean and `una run` could print the `secret` value on every tick. A state labeled higher in `step` or `on_stop` than in the result of `init` stays legal. Edition `0.4` preview: a driven module whose state parameter is labeled below the state it receives is now rejected; label the parameter at least as high.
