- **Accepted: no pipeline operator and no shorthand lambda; method calls already chain** (#35, ADR 0110). `|>` and an `it` shorthand for lambdas are not added: method-call syntax is Una's pipeline, `x.f(a: 1).g(b: 2)`, and a lambda names its parameters. The `|>` shape stays U0101 with the description of ADR 0096 rule 3, and the backlog row of #35 closes as decided. No language rule changes in any edition.
