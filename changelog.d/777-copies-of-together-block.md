- **Accepted: the copies of a `together` block, made in sequential phases and checked before each allocation** (#777, ADR 0113). Native code will copy a block's inputs and results one task at a time, while none of the block's tasks runs code, and check before each allocation that it fits the memory budget, the copy's working memory included. The budget will stop at U6003 at the block instead of being exceeded, and the native case of #314, whose site varied with how threads were scheduled, will stop at one site. Native reference counts and copy marks will share one 64-bit word, 32 bits each, so no heap slot grows; a retain past 4294967295 references to one value, or a copy of more than 4294967295 objects, will stop the run. The interpreter does not change.
