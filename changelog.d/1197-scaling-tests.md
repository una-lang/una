- **Scaling tests that machine load cannot fail** (#1197, #1460). The scaling tests of the checks of calls into a boundary, of dead failure handling, of the charge of installations and of `L_lim` now count their work first: a test-only counter, `pass_steps`, behind `una-core`'s feature `counters` that only tests enable, must grow at most 1.1 times as fast as the size, which a quadratic pass doubles at every doubling; a wall-clock check over 16 times the size, against a bound of 32 times, stays as a coarse backstop. Every wall-clock scaling test of `una-cli`, `una-check`, `una-link` and `una-project` that uses the shared helper `tests/common/timing.rs` now retries a missed bound in up to five interleaved rounds, each size run as often as makes up one run of the largest, keeping the shortest run of each size; the per-doubling bounds are unchanged. A release build counts nothing.
