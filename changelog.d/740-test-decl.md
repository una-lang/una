- **The test declaration is written `test` in edition `0.3`** (#740, ADR 0105). An edition `0.3` package writes `test "name"` where editions `0.1` and `0.2` write `example "name"`, with the same lines and rules; `test` is a keyword there, and a local named `test` is renamed by `una fix`. An `example` declaration in an edition `0.3` package is U0103, "`example` is written `test` in edition 0.3", with the exact rewrite of the keyword that `una fix` applies; its body is still read as a test's. `una test` prints `test` and `tests` for such a package, and its `--json` is the schema `una.test/2`: `una.test/1` with the key `examples` renamed `tests`. Diagnostics that name the declaration say "test" in edition `0.3`. Editions `0.1` and `0.2`, `una.test/1` and the Core export do not change.
