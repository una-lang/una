- **A `hunt` release gate runs the security hunt's generators and a two-run oracle** (#767). `scripts/release-gates.sh hunt` runs a fixed, seeded set of 5,000 generated programs: a program built to break a flow rule must be rejected, a refactor that keeps every label must not turn a rejection into an acceptance, and for an accepted program with a literal labeled above `public`, every variant of that literal must show each observer below its label, at `public` and at `internal`, the same status, output, failure, diagnostics and visible operation events, each variant run twice. The gate fails closed on any finding, any check or run that ends in an unknown way, any nondeterministic run, and any count of judged cases other than the fixed run's; two planted canaries must be caught. Pairs where only one variant aborts on a resource limit are outside the noninterference guarantee and are recorded, not judged. macOS only (its sandbox is `sandbox-exec`); the rest of the oracle's scope and a Linux sandbox are #782.
