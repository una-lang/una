- **`una run` serves** (#1008, #1009, ADR 0123, `spec/31 §1` rule 10 and §7 rule 5), edition 0.4 preview. `una run` of a program whose `main`, or a driven module's `init`, `step` or `on_stop`, uses `HttpServer`, and of a package with a `serve` section, now runs it over live listeners in the interpreter, with no test flag: the serve threads start before `main`, and the run ends at a host stop with exit code 0. What stays closed: `una build` of a program that serves is still a usage error, exit code 2, before anything is made; a `within` in the `serve` section is still U4003; an `https` grant is still refused before `main`, so no plain bytes are served on an `https` address; `--virtual-time` with a `serve:` grant and no `--serve-script` is still a usage error; and the scripted connections of `--serve-script` still run only in the toolchain's own tests. The usage errors of `una build` now say that `una run` serves the program.
