- **`una run` serves** (#1008, #1009, ADR 0123, `spec/31 §1` rule 10 and §7 rule 5), edition 0.4 preview. `una run` of a program whose `main`, or a driven module's `init`, `step` or `on_stop`, uses `HttpServer`, and of a package with a `serve` section, now runs it over live listeners in the interpreter, with no test flag: the serve threads start before `main`, and the run writes one line on stderr for each address it serves, `serving on 127.0.0.1:8080 (granted by the package)` or `` (granted by a `--grant` flag) ``, before its first request. A run that takes host stops, one with a `serve` section or a `main` that says `diverges`, drains at SIGINT or SIGTERM and ends with exit code 0; a server whose `main` does not say `diverges` keeps the default action of SIGTERM and ends at once, exit code 143, with no drain. What stays closed: a `within` in the `serve` section is still U4003; an `https` grant is still refused before `main`, so no plain bytes are served on an `https` address; `--virtual-time` with a `serve:` grant and no `--serve-script` is still a usage error; and the scripted connections of `--serve-script` still run only in the toolchain's own tests.
