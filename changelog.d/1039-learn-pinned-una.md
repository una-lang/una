- **The site gate checks the Learn book with the una it pins** (#1039). `scripts/site-website.sh` checks Una by Example with this checkout's `una` while the release the book's `una.lock` pins is being prepared, and once it is published, or when the versions differ, with that published release, whose archive's SHA-256 must be the one its validation record gives and whose `una --version` must name the pinned version (`scripts/site-learn-una.sh`, with a self-test the gate runs).
