- **The site gate checks the Learn book with the una it pins** (#1039). `scripts/site-website.sh` checks Una by Example with this checkout's `una` when its version is the one the book's `una.lock` pins, and otherwise with that published release, whose archive's SHA-256 must be the one its validation record gives and whose `una --version` must name the pinned version (`scripts/site-learn-una.sh`, with a self-test the gate runs).
