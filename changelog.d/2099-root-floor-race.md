- **A run that loses the root-floor race fails instead of ending with a note** (#2099, security, `spec/30 §14`, ADR 0122 amendment of 2026-11-09, L3). When two runs of `una ita` read a registry's root-version floor at the same time, each compared the root chain it walked with the floor it had read, so the second one to store could hold a root metadata of the same version with another digest, proof that the root chain forked, and still succeed with a note. The store now compares the whole chain walked with the floor again under the floor lock: a stored floor whose version the chain holds with another digest refuses the place, or the bundle of `una ita unbundle`, with U7010, before its checkpoint is stored and before a package of the bundle is written, and the stored floor is kept. This also covers a chain that goes to a higher version and forked below it, which before replaced the floor. The same digest from both runs, and a higher version of the same chain, pass as before; a floor that cannot be stored for another reason is still a note.
