- **Proposed: eliding the run-time checks the verifier proves** (#737, ADR 0112, Proposed). Release builds would drop only the `Int` promotion path and the fixed-width overflow test of operations whose range a proof covers (a proven `overflow` obligation, or an advisory query for `Int` that never changes acceptance), each listed in the build report's `native.elided` with its proof. Every memory-safety, resource, cancellation and division check stays, a wrong proof gives a wrong value and never undefined behavior, and `--no-elision` builds with every check.
