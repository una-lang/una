- **Tests that failed on Linux for reasons of their own now run as written there** (#1920). The poller's huge-timeout test re-arms its fired one-shot registration with a delete and then an add, as the reactors do, since `epoll` refuses a second add with `EEXIST`, and a new test pins that contract on both platforms; the wake pipe placement test holds its descriptors with `dup2` in the child, since `dash` takes no shell redirection above descriptor 9, so its check of a busy limit now runs on Debian and Ubuntu too; four tests of the native backend that shared a package directory with another test now have their own; and the `una-rt` test of a bit set the allocator cannot give runs in a process of its own, so its announced 2^59 bytes no longer end a test that runs a program beside it.
