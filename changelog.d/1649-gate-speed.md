- **Test runs use `cargo nextest`** (#1649). `.config/nextest.toml` runs the tests of all binaries side by side, builds the runtime library once before them, and gives each timing or scaling test the whole machine for itself; a test that links natively no longer rebuilds the library in its own process. `cargo test --workspace --locked` still runs the same tests, and no test is skipped or changed in what it asserts.
