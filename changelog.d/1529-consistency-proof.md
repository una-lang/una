- **Security: a retired witness's cosignature counts offline only with a verified consistency proof** (#1529, ADR 0122 amendment of 2026-11-03, `spec/30 §4`, §9 rules 5, 7 and 9, §15). A provenance, now `ita-provenance/2`, carries the latest checkpoint signed under the last root version and the consistency proof that the lock's point is its prefix, and every load verifies them. Without them, as in a provenance of the earlier format, a point cosigned by a witness the last root retired is unavailable (U7013, exit code 1); `una ita fetch` stores the newer format beside the earlier one, which is kept. Every offline load, and `una ita unbundle`, reads the root-version floor Itaoca stores for the registry: a provenance whose root chain ends below it is refused (U7010), and a floor that cannot be read is unavailable (U7013). The lock's `registry` section records the last root version and its digest (`last root`), which a vendored chain must hold; a lock without the line is U7009, repaired by `una ita lock`. Past the stored floor, or with none, the vendored root chain is trusted on first use. The security hunt's Y3 controls carry the proof, with new forgeries of it and of the root chain.
