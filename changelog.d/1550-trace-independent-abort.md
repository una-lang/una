- **An integer too long for text at an operation aborts natively with or without `--trace`** (#1550, `spec/11 §7`, `spec/16 §3` rule 4): a native executable run without `--trace` went on past an operation whose argument or result held an `Int` of more than 4300 digits and exited 0, where `--trace` and `una run` aborted with U6003. It now writes those values as the event would show them, drops the text and aborts the same way; a value that can hold no `Int` is not written. An argument abort leaves no event for the operation in both engines (natively it used to leave a partial `aborted` one), and in a task the operation no longer runs after it; a result abort leaves the event `aborted`. The native U6003 now names the operation's position, as `una run` does, instead of an unrelated one. The cap and its O(1) decision are unchanged.
