- **Every excerpt in the examples' READMEs is checked** (#827). Each `text` block of `examples/*/README.md` names what it shows in its fence's info string: `una="ARGS"` for what a command prints in the package, which must start and end where the output does unless the block starts or ends with `...`, and `file="PATH"` for an excerpt of one of its files. `crates/una-cli/tests/guide.rs` checks each one, with trailing spaces removed and `...` as the only wildcard, a whole line. A block without a marker fails, and so does an empty excerpt or one whose path leaves the package. The blocks that show what a change to a package reports name the README's mistake they belong to, and are checked next.
