- **Tests: `una check` and `una run` agree on `[run] grants`** (#826, `spec/13 §5`). The behavior #925 fixed is now covered in all four cases: an empty list and a list that lacks a capability are U3012 at check time, as at run time; a list that grants it passes both; and a package that lists no grants passes `una check` and leaves the grants to `--grant`, so `una run` without a flag reports U3012 before the program starts.
