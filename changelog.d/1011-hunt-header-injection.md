- **The security hunt's server run: replies with injected headers** (#1011, ADR 0123 S9). Family N5 echoes a request's decoded query value into a header of the reply, CR, LF, NUL and other control bytes included, and writes header names the host writes itself or that are not tokens, and bodies on `204` and `304`: the reply must fail with `BadReply`, send nothing and keep its reply right, and no byte of the injection may reach the peer. The release gate's fixed run is unchanged.
