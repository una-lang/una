- **A counterexample never shows an empty value** (#668, `spec/13 §1`). When the solver refuted a query but rejected the request for its values, the values were padded with empty text, so a counterexample could read `flag = , y = Unknown#`. The obligation stays refuted, and its counterexample now says `not available (the solver gave no values: <message>)`; in `--json` its `bindings` are empty and a new `unavailable` key holds the message. A term without a value is never shown. The conformance suite and the verifier's corpus cross-check fail on any obligation whose solver gave an error in place of values, whatever its outcome, since it means a wrong solver script (ADR 0101). Proof cache entries written before this change are solved again once.
