- **`una check` and `una build` report U3012 for `grants = []`** (#925, `spec/13 §5`). A listed empty `[run] grants` was treated as absent, so `una check` and `una build` accepted a `main` that uses host capabilities, as `spec/13 §5` did not allow. Such a program never ran: `una run` and the executable stopped with U3012 before starting. A listed `grants`, empty or not, is now the final set for both commands, in every edition.
