- **The Linux release checks its build image's toolchain** (#1926, #1958). `supply-chain/z3.lock` records the Debian package versions of the arm64 build image (binutils, cmake, make, GCC 13, libstdc++ and libgcc development files, glibc) and the SHA-256 of the files the linker puts into the Linux `una` from it (`libstdc++.a`, `libgcc.a`, `libgcc_eh.a`, the start-up objects and `libc_nonshared.a`). `scripts/release.sh` runs the new `scripts/check-toolchain.sh` before it builds `una` and refuses (exit 2) an image whose packages or files differ, so a rebuilt image cannot ship until the lock is updated deliberately. The lock's comment on the Linux Z3 build now names `scripts/build-z3.sh --source`.
