- **Gate tiers: a fast layer per pull request and a nightly full suite** (#1701). The `tests` gate runs `scripts/gate-tests.sh`: a fast subset of a few minutes for changes outside runtime, soundness, security, supply-chain and configuration code, the whole suite for those and for the security, soundness, performance and release workflows, and nightly on `main` (`docs/compiler/testing.md` section 8).
