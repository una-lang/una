- **`scripts/release.sh` builds with the embedded Z3 alone** (#1954). A development library named by `UNA_Z3_LIB`, which `scripts/local-ci.sh` exports for every step and `scripts/z3-library.sh --export` sets in a shell, made una-z3's build refuse the release build beside `UNA_EMBED_Z3`, so the local CI's pack step failed. The script now unsets `UNA_Z3_LIB` once it has chosen the library the lock pins: the release embeds only that library, by its digest, and still fails when no cache entry holds it. A test runs the script with a fake `cargo` and checks the build's environment, with and without the caller's `UNA_Z3_LIB`.
