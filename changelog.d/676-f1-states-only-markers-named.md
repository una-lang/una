- **F1 states that only markers are named with `@`** (#676, `formal/`). A handler installed by `with` is a marker binding `@o` in the model, and the model assumed, without checking, that no other binder of a program is so named. `Program.LWellFormed`, which every certificate requires, now states it: a parameter named with `@` is the marker of an operation its function invokes, and no `let`, case, error, tuple, loop or lambda binder is so named. The whole-program check verifies it (`Fun.markersOk_sound`), so an imported program that names one gets no certificate even if the importer's own refusal of such documents missed it. The re-check of every conformance case and example gives the same verdicts as before. 434 theorems.
