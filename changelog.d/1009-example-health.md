- **`examples/health`, a server example** (#1009, ADR 0123 "A health endpoint", `spec/31 §7`), edition 0.4 preview. The package's `ita.una` grants `serve "http://127.0.0.1:8080"` and names the module `health` in a `serve` section; `handle` answers `GET /health` with `200 ok` and every other request with `404`, and its tests call it with requests from `test_request`. It checks at tier 1 with every obligation proven and passes its tests; `una run` and `una build` of it stay a usage error until the server runs (`spec/31 §1` rule 10). The example tests now read `ita.una` packages.
