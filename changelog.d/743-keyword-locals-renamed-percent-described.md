- **A declaration keyword used as a local name is renamed by an edit, and `%` names the remainder rule** (#743, ADR 0096 amendment of 2026-10-15). Inside a function body or a handler operation body, a `let`, a lambda parameter, a `when` arm binding or a handler operation parameter named with a declaration keyword such as `op`, `kind` or `module` now gets one edit that renames it and its uses to `<word>_value`, including uses in interpolation holes. A name after `.` and an argument label are left as they are. A function parameter and a handler declaration parameter keep the advice, since their names are part of an interface. A `%` gets a description saying that Una writes the remainder as `mod`, which is Euclidean, and gives no edit, since `%` in C, TypeScript and Rust truncates and the two differ on negative operands.
