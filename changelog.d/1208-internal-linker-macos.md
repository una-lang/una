- **`una build` links by itself on macOS arm64** (#1208, ADR 0124 step 3, `spec/16 §6`). The new crate `una-link`, in safe Rust, links the program's object and the runtime built into `una` into a Mach-O executable for macOS 13 and later that loads `/usr/lib/libSystem.B.dylib` alone, with chained fixups bound at load, `__unwind_info`, dead code removed, no debug information, a deterministic `LC_UUID` and an ad-hoc signature with the hardened runtime, so macOS refuses injected libraries and debuggers; `una build` runs no `cc` there, and every output is read back by the linker's verifier. `una build --debuggable` lets a debugger attach. A refusal of Una's own inputs is U8001, and an executable too large to lay out is the new U7015. The report's `native` section gains `linker` and `debuggable`. Linux keeps the system linker until step 4.
