- **The Linux containers get the Z3 library built into una** (#1902). `scripts/local-ci.sh` and `scripts/hunt-linux.sh` mount the local copy of the pinned Z3 tarball that `UNA_Z3_SOURCE` names read-only into their containers (`scripts/z3-source.sh`, which refuses a value that is not a readable file); the build container of `scripts/hunt-linux.sh` mounts the Z3 cache volume and builds `una` with `UNA_Z3_LIB`, so the hunt gate checks with the solver; `scripts/local-release.sh` mounts the cache volume read-only with `UNA_Z3_CACHE` for `scripts/release.sh` and no longer installs a standalone Z3, which no step of it used. A missing library is an error in each.
