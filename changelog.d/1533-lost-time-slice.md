- **Security: a task that starts past its turn's end still yields** (#1533, S-43, ADR 0117 rule 2; amendment draft `docs/plan/0117-seen-value-note-draft.md`): the end of a time slice that came before a task had installed its state could be lost, and then the task kept its worker while other ready tasks on that worker waited, a canceling task among them, beyond the bound of rule 2. The pending end now reaches the task's first check point (edition `0.4` only; no released version has the scheduler).
