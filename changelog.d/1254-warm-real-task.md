- **Security: a public block's timing no longer depends on how many tasks `secret` code started** (#1254, native executables, edition `0.4` tasks, unreleased). Before `main`, a run with threads now runs one real task on every worker through the path every block takes, under no budget and leaving no event or object, so what a task's first run on a worker makes and keeps, in the runtime's thread-locals and in the allocator's per-thread caches, exists on every worker whatever earlier code starts. The timing oracle `a_public_block_s_timing_never_depends_on_how_many_tasks_secret_code_started` found the channel on `main` on 2026-10-27; ADR 0116 amendment P8's no-op warm-up had left it.
