- **The HTTP server's request reader and reply writer** (#1004, ADR 0123 step 2, `spec/31 §3` to §5). `una-http` gains `request`, which reads one request fed in pieces, with no I/O, on the strict framing of #1003: limits checked before bytes are kept (`414`, `431`, `413`), exactly one `Host` of strict syntax, absolute-form targets rewritten only for their own host and scheme, `415` for a content coding, `417` for an unknown expectation, `100-continue` reported, the connection's headers removed, and the next pipelined request left unread. It also gains `reply`, which checks a reply (`BadReply` for a reserved or injected header, a body on `204` or `304`, too many headers) before writing its bytes with `Date`, `Content-Length` and a default `text/plain; charset=utf-8`. No construct is added yet.
