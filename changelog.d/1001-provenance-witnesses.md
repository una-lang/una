- **Security: a vendored or fetched registry release no longer loads on a provenance whose point is counted by a revoked witness, or by fewer witnesses than a later root version requires** (#1001, ADR 0122 amendment 7c, `spec/30 §9` rule 7, §11 rules 8 and 9). Loading counted the cosignatures of a provenance's checkpoint by the root version the checkpoint names alone, so a witness that a later stored root version lists in `witnesses-revoked` still counted, and so did a threshold lower than the last stored version's. It now counts them as the registry client does: never a revoked witness, and with the larger of the two thresholds. A provenance written by `una ita fetch` was already counted so when the release was fetched, so only a provenance changed after that is refused (U7010).
