- **Security: an operation served by a handler installed in a callee under a `secret` branch no longer shows in the trace** (#1544, `spec/26 §6` rule 4). A function with no effects of its own that installs a handler and performs an operation served by it, called under a program counter above `public`, appended that operation's event, so whether the event occurred revealed the secret. An operation served by an instance that quiet code installed, `with:<h>#q`, now appends no event and takes no `seq`, in both engines and in every edition. Where code is quiet only by the conservative rules (an effect floor, a decision on values of a type parameter), such operations lose their events: the safe direction.
