- **Parsing JSON objects is linear when their keys are in order** (#886, spec/23 §6 rule 1). Both engines build a parsed object's map in bulk from the parser's sorted entries, rather than inserting each key, so parsing JSON whose objects' keys arrive in order, as `to_json` writes them, takes time linear in its size. A test bounds the key comparisons per entry at sizes up to 2^16 in both engines.
