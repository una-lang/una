- **Structural equality on shared parts** (#815): `==`, `!=` and `contains` compare each distinct pair of parts once, in both engines, so values that share their parts no longer take time in the number of paths through them, which doubles with each level of sharing. A comparison takes time and space in the number of distinct pairs of values with parts it meets, compares leaves as it meets them, and allocates no set for its first 1024 steps. It counts the pairs of values with parts it holds at 128 bytes each against `--max-memory`, and over the budget it aborts with U6003 at the comparison, or stops its task there (ADR 0061, Amendment of 2026-10-17; `spec/11 §7`). The runtime functions that compare take the comparison's site first, under new names (`una_rt_equal_at`, `una_rt_contains_at`, `una_rt_generic_equal_at`, `una_rt_generic_contains_at`), so a `libuna_rt.a` built before this change fails to link with the stale-runtime message instead of misreading their arguments: rebuild it with `cargo build -p una-rt`.
