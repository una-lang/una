- **Per-operation labels in edition `0.3`, part 1** (#566, ADR 0094). An operation in a header's `uses` brackets can carry `gives` and a label, `uses @service_files: Files[owner gives internal[Service]]`: through that binding the operation's answer, whether it failed and its payload carry the label, so the flow rules keep a service's answer from reaching the requester. Passing a labeled binding to a callee that reads the operation lower, by name or with `with`, is the new U3022, whose repairs never lower a label; rebindings and narrowings keep the labels; a function whose `uses` label an operation is not a value (U3006). `gives` is a contextual keyword of edition `0.3` (U0103 before it, U0101 in a function type, U7002 in a ceiling). Inferred labels of private functions, locked labels under `[contracts]` and the H5 premise in the build report follow in parts 2 and 3 (`docs/plan/0094-operation-labels-design.md`).
