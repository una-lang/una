- **`una lsp` checks packages of editions `0.4` and `0.5`** (#2298, ADR 0063 rule 10 read with ADR 0122 rule 2). The language server found a file's package only through a `una.toml` above it, which these editions replace with `ita.una`, so it checked each module of such a package alone, as a single file: an import of another module of the package did not resolve, and the package's lock, dependencies and boundaries were not read. It now takes the nearest directory above the file that holds `ita.una` or `una.toml`, the manifest that `una check` reads, and reports at tier 0 and tier 1 what `una check` reports for the package. The cost is one more file test per directory above the file, O(depth of the path).
