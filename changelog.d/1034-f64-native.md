- **`F64` in native code** (#1034, #819, ADR 0114 rules 6 and 9.6, `spec/29 §9`). `una build` compiles programs that compute with `F64`, every value boxed until the raw cells of ADR 0107 land, every operation computed by the same routines as the interpreter's, so both engines print the same bits. A native executable of edition 0.3 writes the default floating-point environment on each of its threads and tests it before `main`, stopping with U6006 when it differs.
