- **Requirement name suggestions no longer overflow or probe quadratically** (#1474, security: the U1005 suggestion for a requirement identifier whose derived name ends in `_18446744073709551615` and is taken overflowed a u64, a checker panic in debug builds and a wrap in release builds; when the number space is exhausted the suggestion now appends `_1`, as in `X_18446744073709551615_1`; the free number is found by one binary search per identifier over the identifiers read once, O(n log n) for n identifiers instead of O(n^2) on a run of taken names; suggestions for ordinary names are unchanged)
