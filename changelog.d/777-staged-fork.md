- **The copies of a `together` block are made before its tasks run, and every step is checked** (#777, ADR 0113 step 2). Native code forks a block's tasks batch by batch: the block copies a task's inputs out, the task copies them in, and only when the whole batch has does any task run, so the site where a copy stops no longer depends on how threads are scheduled (#314 stops at one site again). Each step of a copy, its containers included, is announced and checked against the budget before it allocates, with the copies of other blocks in flight, so a copy reports U6003 instead of reaching the allocator's hard ceiling. A thread that cannot start, a copy of more than 4294967295 objects, and a panic during a copy each end the block before any task runs. The interpreter does not change.
