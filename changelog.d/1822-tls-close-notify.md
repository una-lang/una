- **A TLS response cut by a bare close fails** (#1822, `spec/24 §3` rule 3). Over `https`, a response whose body ends at the end of the connection (no `Content-Length`, not `chunked`) is now `Protocol` unless the server sent TLS's `close_notify` before closing; before, an on-path attacker could truncate such a body with a TCP FIN and the program received it as complete. A response delimited by `Content-Length` or by its last chunk still succeeds when the server then closes without `close_notify`. Plain `http` is unchanged. Both engines.
