- **On Linux, the solver child's filter refuses opening a file with `EACCES`** (#1455, ADR 0124 rule 7, probe P6). glibc 2.39 reads `/sys/devices/system/cpu/online` again each time it counts processors, during the query, so the filter's tripwire on `openat` killed the solver child (U5003, "the solver child broke its confinement (SIGSYS)") and every verifying run failed on such a system. `open`, `openat` and `openat2` now fail with `EACCES` without running, as rule 7 provides, and glibc falls back to `sched_getaffinity`. No call became allowed: `creat` and every other tripwire still kill, and the child still opens nothing after the filter. New tests run the filter's program over every call number and open a real file under the filter. macOS is unchanged.
