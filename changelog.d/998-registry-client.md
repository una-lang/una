- **The registry client** (#998, ADR 0122 rules 26 and 34 to 39, `spec/30 §14`). `una ita lock`, `update` and `add` resolve the needs of a source of `sources` from its registry, read from a mirror directory with `--mirror <source>=<location>` and verified from the pinned root to every entry: the root chain and its expiry, checkpoints with their witnesses, freshness and floors, the log's tiles and proofs, each name's whole chain against the name map, the owner's keys at each statement's position with revocations and recoveries in witness time, and rule 26 between releases. `una ita fetch` fills Itaoca with the locked releases, each archive checked against its statement, what its code uses included, and a verified release that a need names is mounted in the program. A change of an owner's keys needs `--accept-key` (the new code U7014). A source with no mirror is refused (U7013): this release has no https transport, and plain `http://` is never used.
