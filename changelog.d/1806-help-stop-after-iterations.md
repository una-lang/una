- **`una run --help` describes `--stop-after-iterations` correctly** (#1806, `spec/26 §6` rule 1). The help text called the flag a request for a host stop once N iterations had started. It is a budget of N iterations for each `for ever` loop instance, the driver's loop included, which ends at the start of its iteration N + 1; it is no host stop request and starts no grace period. Only the text changes; the runtime already did this.
