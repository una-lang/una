- **The runtime inside `una`** (#1207, ADR 0124 rules 12, 14, 15, 18 to 20 and 28, step 2, `docs/plan/0124-step2-design.md`): `scripts/release.sh` builds `libuna_rt.a` first, strips its debug sections and builds `una` with it embedded by digest (`UNA_EMBED_RUNTIME`, `UNA_EMBED_RUNTIME_SHA256`, checked by `crates/una-cli/build.rs`); a release `una build` links that runtime, checks it against its digest before every link (U8001, exit code 3, when it is missing or damaged) and reads no `UNA_RT_LIB` and no `lib/`, so a runtime older than `una` can no longer fail the link (#203); until step 3 it writes the runtime for `cc` into the link's private directory (mode 0700) as a new file of mode 0600, removed with it; development builds keep the search of ADR 0059 rule 2; `una --version` says `development build` without the embedded runtime too; the build record gains `runtime_sha256`, and the report `native.runtime_sha256` (`spec/13 §6`, `spec/16 §2` rule 8).
