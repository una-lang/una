- **Soundness: the label of a limited request covers its callers' work** (#1147, ADR 0116 P8, slice T1 of its amendment, ADR 0117 IF4, `spec/27 §9` rule 5). `L_lim` covered only the body of the function that holds each request. With `at most 1 per minute`, a second request waits at the bucket for a minute less the time spent since the first, and `--http-timeout` turns that wait into `TimedOut`, so a caller that worked on a `secret` between two calls of the function that makes the request decided, unlabeled, whether the second one was sent. Each request's label now joins `τ⁰` of the body of every ancestor of its function in the call graph of ADR 0116 P1, its own function included, with the preview's `τ_conc`: the graph has the operations of handlers, reached through the operations of their capabilities, and one node for every lambda, reached by every call of a function value, so a handler's operation that works on a `secret` between two requests is covered too. It is computed in linear passes over strongly connected components, and U4001 names the nearest ancestor that raised it, with that body's label. The limits of S5 have not shipped in a release; a program this now refuses was leaking. A two-run differential test, changing only the secret, covers it.
