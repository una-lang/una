- **Release scripts: no override of the random source, and no test hooks in a release** (#1015). `scripts/release.sh` refuses build flags, in the environment or a cargo configuration file, that set `getrandom_backend`, which would replace the operating system's random source in the shipped `una` and `libuna_rt.a`. `scripts/check-release.sh` fails when a shipped `una` or `libuna_rt.a` holds the marker of keyed hashing's test-only hooks, by `nm` or by its bytes.
