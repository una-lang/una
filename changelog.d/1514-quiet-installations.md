- **Security (S-41): handler installations under a `secret` branch no longer move the instance ids of later public installations** (#1514, `spec/26 §6` rule 4). A `with` under a program counter above `public`, written there or in a callee, was counted by the run-wide count behind `with:<h>#<n>`, so the id of a later public installation of the same handler revealed the secret. Such installations, and every installation in quiet code, now take no number, `with:<h>#q`, in both engines and in every edition, so no instance id depends on the secret. Still open: the occurrence of operations of capabilities that accept `secret` (S-42, #1515) and the slots and parks of quiet tasks (#1545).
