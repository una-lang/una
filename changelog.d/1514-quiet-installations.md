- **Security (S-41): handler installations under a `secret` branch no longer move the instance ids of later public installations** (#1514, `spec/26 §6` rule 4). A `with` under a program counter above `public`, written there or in a callee, was counted by the run-wide count behind `with:<h>#<n>`, so the id of a later public installation of the same handler revealed the secret. Such installations are now quiet and counted apart, `with:<h>#q#<n>`, in both engines. Still open: a `start` under a `secret` branch inside a public `tasks` statement (S-40, #1512), and the occurrence of operations of capabilities that accept `secret` (S-42, #1515).
