- **Host stops, edition 0.4 preview** (#943, ADR 0116 rules 12 to 19 and 21, `spec/26 §6`). SIGINT, SIGTERM, `--deadline <seconds>` and `--stop-after-iterations <n>` are host stop requests of `una run` and executables, sticky for the rest of the run: every `for ever`, the driver's loop included, ends at its next iteration start with a `stop` event in the trace and runs its `on stop`, and the run then ends normally. An `Http` operation in the body of a `for ever` that waits, or starts, after a request fails with the new variant `HttpError.Interrupted` (edition 0.4 only). The hard stop comes at the end of `--stop-grace <seconds>` (default 10) or at a second request and cancels the run at its next call or loop iteration with U6007, exit code 1; a third request, or a second grace period after the hard stop, ends the process with SIGTERM. Signal handlers are installed only for runs whose `main` says `diverges` or that run a driver, in the new `una-sys` crate. The report's `out_of_model` list gains "the time of a host stop", "interference of the host's load with the timing of an expression" and "uncatchable termination".
