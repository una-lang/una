- **A correctly rounded `exp` in una-core** (#1061, ADR 0114 rule 18, step 2, part 1), not yet reachable from a program. `una_core::elementary::exp` evaluates in fixed point on Una's own integers with a rigorous error bound and returns a result only when both ends of its bracket round to the same `F64` (Ziv's strategy, from 128 bits, doubling), so it is correctly rounded on every input with no platform math library and no table; tests check it against an independent interval oracle on dense grids, every binade, the thresholds and the hard cases near 1.
