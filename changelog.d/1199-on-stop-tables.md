- **A hash table made in `on stop` or in a `for until` condition gets its key** (#1199). The analysis that decides whether a run reads the process key (ADR 0119 rule 9) now walks the `on stop` block of a loop and the condition of `for until`. A run whose only table came from one of them stopped with an internal error at the table's creation; it now reads the key before `main` and runs.
