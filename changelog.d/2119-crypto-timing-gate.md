- **The release gates time the cryptography** (#2119, ADR 0133 rules 9 and 10): the gate `timing-channels` of `scripts/release-gates.sh`, and the step of the same name of `scripts/local-ci.sh`, now run, after the timing oracles and in the same release build, the statistical timing tests of `una-crypto` (`cargo test --release --locked -p una-crypto --test timing -- --ignored --test-threads=1 --nocapture`) and its scaling tests (`cargo test --release --locked -p una-crypto --test perf -- --test-threads=1 --nocapture`), which the ordinary test run ignores or, in a debug build, passes without measuring. In the gate the three commands always run and one that fails fails the gate, so the nightly release run holds each statistic in the log of `timing-channels`. Before, no gate ran either file. The timing test of `ct::eq` samples its two classes on one buffer, 64 calls per sample after a warm-up, with the same claim and the same limit: with two buffers their placement in memory differed with the class, and the statistic left the limit, with either sign, on a loaded machine. No behavior of a program changes.
