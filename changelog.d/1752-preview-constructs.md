- **`una report` names the preview constructs a package uses** (#1752, part 2, ADR 0121 rule 8, `spec/13 §6`): the report's `edition` section gains `preview_constructs`, each construct of the edition ledger that the root package uses, with its record, its number of sites and the names of its unsettled points, ordered by record, then construct, and `[]` for a package of a stable edition or of edition `0.3`. The human `edition:` line lists them, as `edition: 0.5 (preview): sum (ADR 0120, 1 site; unsettled: the accumulation order of 0120's kernels (L, KB)), ita.lock (ADR 0122, 1 site), ita.una (ADR 0122, 1 site)`. The key is additive, and the schema stays `una.report/2`. Sites are counted from Core IR, the checker (for `Map.update`, which elaboration lowers), the syntax tree (imports and `diverges`), the tokens (`simd` as a name and the labels `with:` and `and:`) and `ita.una`, once each, in O(n) for a package of size n; a dependency's constructs are not the root's. A test has one package per ledger entry, so a construct added to the ledger without a counter fails. The ledger gains `std.time`, and lists `simd` as a name of edition `0.5` in place of the clause `simd required`, which is refused until it lands.
