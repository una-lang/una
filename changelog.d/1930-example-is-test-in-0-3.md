- **Edition `0.3` preview, a change that may need edits: an `example` declaration is now U0103** (#1930, #740, ADR 0105 rule 3; kind: stricter). An edition `0.3` package that v0.3.16 accepted with `example "adds two numbers"` is now rejected with U0103, "`example` is written `test` in edition 0.3", at each such declaration, so `una check` and `una test` fail on it until it changes. Migration: run `una fix` in the package, which rewrites the keyword, `example "adds two numbers"` to `test "adds two numbers"`, with the same body, and renames a local named `test` to `test_value`, since `test` is a keyword in edition `0.3`; then rerun `una check` and `una test`. Editions `0.1` and `0.2` keep `example` and do not change. A package of edition `0.1` or `0.2` that moves to edition `0.4` with `una migrate` keeps its `example` declarations, which are U0101 in edition `0.4` with no rewrite: set `edition = "0.3"` in its `una.toml` and run `una fix` before `una migrate`, or write `test` by hand.
