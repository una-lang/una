- **The contributor guide says what a Linux build of `una` needs** (#1958). `CONTRIBUTING.md` gains a section "Building on Linux": every Linux build of `una`, a development build included, needs the toolchain's static `libstdc++.a` and `libgcc.a` (on Fedora and RHEL, the package `libstdc++-static`), since `crates/una-z3/stage.rs` links the solver's C++ runtime statically (#1956); the release image's packages and the files the linker puts into `una` are pinned in the `[toolchain.<target>]` and `[toolchain-files.<target>]` tables of `supply-chain/z3.lock`, and `scripts/check-toolchain.sh` and `scripts/load-commands.sh` enforce them. The README's "Build from source" names the static `libstdc++.a` among the prerequisites. No behavior changes.
