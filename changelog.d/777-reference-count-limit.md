- **A native reference count is 32 bits, and a retain at its limit ends the process** (#777, ADR 0113 step 1). A retain past 4294967295 references to one value stops with one line on stderr: U6003 when the run holds the memory that many references take, else U8001 as an internal error. No count ever wraps, and no heap slot grows when the copies of a `together` block gain their marks.
