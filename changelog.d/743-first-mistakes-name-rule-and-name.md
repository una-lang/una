- **Common first mistakes are reported with their rule and a name to use** (#743). A reserved keyword written as a module path segment or an operation name, such as `module when` or `op take`, is now reported as "`when` is a reserved keyword, so it cannot be a module path segment", with a free name to use instead (`when_module`, `take_op`). A requirement identifier off the convention gets a suggestion derived from its own name (`SOLD_OUT` gives `SOLD_OUT_1`, the first free one) rather than the guide's example. That suggestion is an edit when no `derived from` clause names the identifier, and otherwise advice that lists those clauses. A method such as `to_int()` in a contract now says what the refinement language offers instead.
