- **A wide range in a `together for` is U6003 in native code too** (#773). A `together for` over a range makes its list before its tasks, and the interpreter checks the memory budget at each element. Native code did not, so a wide range under `--max-memory` grew past the allocator's hard ceiling and the executable aborted on a signal where `una run` reported U6003. The native runtime now checks the budget at each element and ends the run with U6003 at the loop, as the interpreter does. The runtime entry `una_rt_range` takes the loop's site.
