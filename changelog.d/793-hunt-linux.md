- **The `hunt` release gate runs on Linux** (#793). `scripts/hunt-linux.sh` and the new gate `hunt-linux-arm64` run the same fixed run in a hardened container (no network, read-only root, no capability, not root, limits on processes, memory and time), where Landlock (ABI 6 to 8) confines each run of the compiler to its own directory and the mock's port and scopes its signals; the gate refuses to run when any of these is missing. On both platforms every run now writes only in a directory made for it, and its process group is killed when it ends. A new canary checks on both platforms that a run cannot write outside its directory or open another socket.
