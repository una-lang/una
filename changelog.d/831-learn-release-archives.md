- **The `site` gate checks the Learn release's downloads** (#831). When the pinned website's `learn.lock` names a Una by Example release, `scripts/site-learn-release.sh` downloads it from github.com and fails unless it is published and holds exactly the files the build makes from the pinned commit, every archive and `SHA256SUMS`, byte for byte, and nothing else; the gate's output records each file's SHA-256. The release line is read with the website's grammar, and the website's own reading of the lock must name the same repository, commit and release; a release line that does not parse, or two release or repository lines, fail. The release gates unset the site scripts' source overrides, and the gate runs the script's self-test first.
