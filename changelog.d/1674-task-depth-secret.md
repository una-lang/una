- **A request task whose depth depends on `secret` data is refused** (#1674, ADR 0123 IF6, `spec/31 §1` rule 5 item 6). A started task past `--task-depth` ends alone and is answered `500`, so its status told a peer how deep it recursed; a `start` that moves a reply right is now checked under a depth label, what decides each call its task can run (conditions, short-circuit operands, the function value called, the list a prelude function applies a lambda over), and U4003 refuses one whose calls data above `internal` decides, as in a probe that recovered a secret integer by the length of the request body. The default of `if error use` now runs under the label that decides the failure, so its effects and calls are checked under it.
