- **A request task that can recurse and hold `secret` data is refused** (#1674, ADR 0123 IF6, `spec/31 §1` rule 5 item 6). A started task past `--task-depth` ends alone and is answered `500`, so its status told a peer how deep it recursed, as in a probe that recovered a secret integer by the length of the request body; a `start` that moves a reply right is now U4003 when its task can recurse, call a function value or reach code the checker does not see, and can hold data above `internal`, a coarse rule computed once per package in linear time. The default of `if error use` now runs under the label that decides the failure, so its effects and calls are checked under it.
