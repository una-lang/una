- **One bound for a check's packages, the published files counted, and no silent default edition** (#2400, #2401, #2402, `spec/30 §1` rule 4, §9 rule 1; kind: U7008, U7010). The walk of `src/` counted only modules against the 10,000 files of a package, so `una check` accepted a package that `una ita publish` refused. It now counts the manifest and the `README.md`, `CHANGELOG.md` and license files at the top as well (#2400). The 256 MiB bound held for each package alone, so a root that named many path dependencies could hold that much per dependency. The root and all its path dependencies now share the 256 MiB, and the dependency that would pass it is refused at its need. A package names at most 1,000 path dependencies, and the check of a directory named twice is linear (#2401). A loose file whose nearest manifest is there but does not read (a directory, a FIFO, past its bound, unreadable) was checked under the default edition 0.1. It is now refused with an error that names the manifest. The default holds only when no manifest is above the file (#2402). O(needs + bytes read).
