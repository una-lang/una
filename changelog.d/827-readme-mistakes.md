- **The examples' READMEs check what each mistake reports** (#827). Each change a README's common mistakes describe is a set of files under `tests/fixtures/examples/NAME/mistakes/N/`. `crates/una-cli/tests/guide.rs` lays them over a copy of the package and requires `una check .` to reject it. It then checks the README's diagnostic as an excerpt of what the check prints, and the changed code it shows as an excerpt of the changed file.
