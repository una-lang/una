- **The formal re-check no longer rejects a pure call of a function with `uses of`** (#1676, ADR 0062). F1 has no effect polymorphism and reads a function with `uses of` as one that performs an operation, so a caller that declares none and gives it only functions with no `uses` was rejected although it performs nothing. Such a caller is now reported as not re-checked, a form F1 does not model. No declaration becomes accepted.
