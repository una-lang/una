# The targets a release ships (#1903, docs/release-gates.md §2, "The shipped targets"): one
# target triple per line, in the order the archives are built; a line that starts with `#` and a
# blank line are ignored. This is the only list of them, read through scripts/release-targets.sh,
# which fails closed. scripts/local-release.sh builds an archive of each and no other,
# scripts/release.sh and scripts/check-release.sh refuse any other target, and the tests of
# supply-chain/z3.lock and install.sh read it. A target added here also needs its [library] line
# in supply-chain/z3.lock and the native evidence of ADR 0124 rule 31; x86_64-unknown-linux-gnu
# needs a native x86-64 Linux host for that (#1442), so it is not listed.
