# U7015: The executable cannot be laid out: a branch beyond its target's range, or a section larger than its format allows

U7015 reports that the program's code and the runtime cannot be placed within the limits of the target's format. No file is written.

## Why Una rejects it

`una build` links the executable with its own linker (ADR 0124 rules 22 to 25, `spec/16`, "Linking"). The limits of the target's format are:

- On arm64, a branch reaches at most 128 MiB in either direction and a page address 4 GiB, and the linker adds no range-extension thunks.
- The image must stay below 4 GiB.
- The `__eh_frame` that compact unwind encodings point into must stay below 16 MiB.

`una check` never reports U7015, since it is a property of the built executable, not of the program's text, so this text has no example.

## How to fix it

No program of the repository comes within a factor of 50 of these limits, so the cause is a program whose generated code is that large. The repair is to split the work into smaller functions and data, or to keep large tables out of the program's text.
