# U2012: `result` outside `ensures` or `expect`

`result` names the value that a function returns, so it has a meaning only in an `ensures` clause and, for examples, in an `expect` line (`spec/02 §8`). In a body, the returned value is the last expression; a `requires` clause states a condition over the parameters.

## Failing example

```una
module demo

pub positive(x: Int) -> Int
  requires result > 0
=
  x
```

## Fixed example

```una
module demo

pub positive(x: Int) -> Int
  requires x > 0
  ensures result > 0
=
  x
```
