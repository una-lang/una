# U4003: Sink label exceeded

Every argument of a capability operation is a sink with the operation's `accepts` label, `public` when the operation declares none (`spec/05 §2`, `spec/07 §4`): the data an operation sends outside the program, every label of its type, and the program counter under which it runs, must be below that label. Interpolation keeps the labels of what it interpolates, so printing `"id {phone}"` of a `secret` phone to `Console`, which accepts `public`, is U4003. The repairs that keep the label come first: send only the data, or the fields, that the operation accepts, or send the value to an operation that accepts its label. Declassifying through a policy is the last repair, marked as an escape (ADR 0095): the guarantee then rests on the policy's trusted code, whose labels are not checked.

What `Env.get` and `Files.read` return is `internal`, so printing it, or anything computed from it, is U4003 too, and no label of the program can be lowered to fix it. When that data must be printed, the escape is the only route: declassify it through a `policy` in a module that both its header and `una.toml` mark trusted, and call the policy where the data is printed, as the second fixed example does. The build report lists every call of a policy with its purpose and owner.

## Failing example

```una
module demo

pub greet(name: secret Text) -> Unit
  uses @console: Console[print]
=
  @console.print("hello {name}")
```

## Fixed example

```una
module demo

pub greet(name: Text) -> Unit
  uses @console: Console[print]
=
  @console.print("hello {name}")
```

## Fixed example: data from the environment, through a policy

`una.toml`
```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.2"

[trusted]
modules = ["release"]
```

`src/release.una`
```una
trusted module release

pub policy shown_name
  from internal Text
  to public Text
  via as_shown
  purpose "greet the user by the name the environment gives"
  owner demo_owner

as_shown(name: internal Text) -> public Text = name
```

`src/demo.una`
```una
module demo

import release (shown_name)

pub main() -> Unit
  uses @console: Console[print]
  uses @env: Env[get]
=
  let name = @env.get("USER")
    if none use "nobody"
  @console.print("hello {shown_name(name)}")
```
