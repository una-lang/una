# U4005: Invalid policy (public `via`, or type mismatch)

A policy's `via` function computes the declassified value, and the policy is its only entry point (`spec/07 §5`): the `via` function is a private function of the policy's trusted module, its one parameter has the type of `from` and its result the type of `to`, refinements included, since only labels differ, it has no `requires` clause, since a policy call checks its argument against `from` only, and no other code uses it. Inside it no label is checked. The message says which of these fails.

## Failing example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.1"

[labels]
categories = ["PII"]

[trusted]
modules = ["keys"]
```

`src/keys.una`

```una
trusted module keys

pub policy mask
  from secret[PII] Text
  to internal Text
  via masked
  purpose "show the last digits"
  owner privacy

pub masked(t: secret[PII] Text) -> internal Text = t
```

## Fixed example

```toml
[package]
name = "demo"

edition = "0.1"

[labels]
categories = ["PII"]

[trusted]
```

```una
  owner privacy

masked(t: secret[PII] Text) -> internal Text = t
```
