# U3032: A `simd required` clause outside a `systems` package of edition `0.5`

The `simd required` clause of ADR 0120 rule 58, `simd required target neon, avx2` after a function's `ensures` clauses, requires that the function's loops use the processor's vector instructions. It is legal only in a package of edition `0.5` whose profile is `systems` (ADR 0109 rules 1 and 5): a construct that only `systems` may use. Anywhere else, in an `app` package, in a single file or in an earlier edition, it is U3032.

The repair is to declare the profile in the package's `ita.una`, with the head line `profile systems`, and the run's memory budget with the `run` line `max_memory`, which a `systems` package with an entry declares. Or remove the clause: without it the same loops keep their meaning, and the runtime may still vectorize them.

The clause lands with its slice of ADR 0120. Until then the release reads no `simd required` clause, so no program reports U3032, and this text has no example of its own.
