# U7003: Escape budget exceeded

`checked` replaces a static proof with a runtime test, so each module may use it only as many times as `[escape_budget] checked_per_module` in `una.toml` allows; the default is 0, and a file checked on its own has the default (`spec/06 §6`). U7003 reports the first use beyond the budget, with the later uses as related locations. Prove the fact statically with a refined type or a `requires` clause, or raise the budget in `una.toml` and explain the escape in review.

## Failing example

```una
module demo

kind ParseError = | Empty

pub nonempty(raw: Text) -> Text
  fails ParseError
=
  checked(raw, raw.len > 0) else fail Empty
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.1"

[escape_budget]
checked_per_module = 1
```

`src/demo.una`

```una
module demo

kind ParseError = | Empty

pub nonempty(raw: Text) -> Text
  fails ParseError
=
  checked(raw, raw.len > 0) else fail Empty
```
