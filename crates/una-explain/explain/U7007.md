# U7007: A form of a preview edition that a release changed or removed

A package of a preview edition uses a form that a later release of that edition changed or removed. U7007 reports it at the form, names the release that changed it, and gives the new form as its first repair: an edit when the rewrite is local and mechanical, which `una fix` applies, and otherwise a description of what replaces it.

## Why Una rejects it

A preview edition may still change (ADR 0121 rule 3), but never silently: a program that one release accepts either gives the same result in a later release or is rejected with a diagnostic (rule 4). When a construct gets a new form, the old one is U7007 for as long as the edition is served, and after it becomes stable (rules 5 and 16), so a package that moves to a new release learns of each change at its site.

In edition `0.5`, the binding words are `const` and `var` (ADR 0137): `let` is reserved, and each `let` is U7007, "this form of edition 0.5 changed in release v0.5.2: `let` is written `const`, or `var` for a binding that is reassigned". Its repair is the exact rewrite: `let x` becomes `const x`, and `let edit x` becomes `var x`, keeping the annotation and the value. `una fix` applies it. Editions `0.1` to `0.4` keep `let` and `let edit`.

## How to fix it

- Apply the repair, or run `una fix`, which applies every exact one: write `const` for a binding that never changes and `var` for one the function assigns again.
- A package that stays on an earlier edition keeps its forms: U7007 appears only in the edition that changed the form.

## Failing example

`ita.una`

```una
ita demo
  version 0.1.0
  edition 0.5
```

`ita.lock`

```una
lock 1

solver
  encoding "una-smt-1"
  name "z3"
  version "5.1.0"
  logic "QF_UFLIA"
  steps 5000000
  seed 0
```

`src/demo.una`

```una
module demo

pub total(xs: List[Int]) -> Int
=
  let edit sum = 0
  for x in xs
    sum = sum + x
  sum
```

## Fixed example

`ita.una`

```una
ita demo
  version 0.1.0
  edition 0.5
```

`ita.lock`

```una
lock 1

solver
  encoding "una-smt-1"
  name "z3"
  version "5.1.0"
  logic "QF_UFLIA"
  steps 5000000
  seed 0
```

`src/demo.una`

```una
module demo

pub total(xs: List[Int]) -> Int
=
  var sum = 0
  for x in xs
    sum = sum + x
  sum
```
