# U5003: Solver missing or version mismatch

Tier 1 runs Z3 at the exact version that `verification.lock` pins, so that every proof can be reproduced (`spec/12 §5`, ADR 0003). When `z3` is not on the path, or reports another version, `una check` stops before discharging any obligation that the proof cache does not hold, and points at the `solver_version` of the lock. Install the pinned version with `scripts/install-z3.sh DIR` and put `DIR/bin` on the path; `una check --tier 0` checks everything else without a solver.

## Failing example

`verification.lock`

```toml
encoding_version = "una-smt-1"
solver           = "z3"
solver_version   = "4.8.12"
logic            = "QF_UFLIA"
step_budget      = 5000000
random_seed      = 0
```

`src/demo.una`

```una
module demo

pub kind Seats = Int in 0..5000

pub book(seats: Seats) -> Int = seats

pub first() -> Int = book(1)
```

## Fixed example

`verification.lock`

```toml
encoding_version = "una-smt-1"
solver           = "z3"
solver_version   = "5.1.0"
logic            = "QF_UFLIA"
step_budget      = 5000000
random_seed      = 0
```

`src/demo.una`
