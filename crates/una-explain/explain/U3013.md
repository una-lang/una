# U3013: Effectful or fallible call nested inside an expression

A capability operation, or a call of a function that uses capabilities or can fail, is nested inside another expression or an argument.

## Why Una rejects it

One effect per line: a capability operation, or a call of a function that uses capabilities or can fail, is the whole expression of a statement, a `let` right-hand side or a final expression, optionally wrapped in `attempt` (`spec/04 §4`). It cannot be nested inside another expression or an argument.

This fixes the order of evaluation, gives every failure a handling site and makes every effect visible on its own line.

Example `do` lines are exempt (`spec/08 §2` rule 5).

## How to fix it

Bind the result with `let` first, on the line before. Where that would not resolve it, or would change what the program does, the message names the form for the place where the call stands:

- Under a nested `attempt`, bind the whole `attempt`, as `let outcome = attempt f(x)`, and use `outcome`. Binding the call alone leaves its failure unhandled (U3007). This holds in every place below: where the advice puts the call, it puts the bound `attempt`.
- In the body of a lambda, which is one line and holds no `let`, move the work into a named function and pass that function.
- In code that runs only when something else decides, a `let` before the statement would run the call every time:
  - in the value of `if error use`, use a value without effects that cannot fail, or bind `attempt` of the first call and branch on it with `when`, with the call in an arm `is Err(e) ->` written as a block;
  - in the value of `if none use`, use such a value, or bind the value without that clause and branch on it with `when`, with the call in an arm `is None ->` written as a block;
  - in a branch of `if ... then ... else`, or in the right operand of `and`, `or` and `implies`, write an `if` on several lines, with the call as a statement or `let` of the branch that needs it;
  - in a one-line arm of `when`, write the arm as a block, with the call as a statement or `let` of the arm.
- A branch of `together` is one `let`: call a named function from the branch's `let`, and put the call in its body.
- A call with `edit` or `take` cannot be wrapped in `attempt`: drop the `attempt`, make the call itself the whole expression of a statement or `let`, and handle a failure with `if error`.
- A `do` line of an example binds nothing, so a call with `edit` or `take` goes in a function that edits a local copy, which the `do` line calls.

## Failing example

```una
module demo

capability Clock
  op now() -> Int

pub later() -> Int
  uses @clock: Clock[now]
=
  1 + @clock.now()
```

## Fixed example

```una
module demo

capability Clock
  op now() -> Int

pub later() -> Int
  uses @clock: Clock[now]
=
  let now = @clock.now()
  1 + now
```
