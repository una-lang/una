# U4001: Flow to a lower label

A label says who may observe a value, and data never flows to a lower label (`spec/07 §3`): a value flows into a parameter, a field, an annotated `let`, a policy's `from` type or a function's result only when each position of its type is labeled below the declared label there. Labels follow data: an operator, an interpolation or an equality takes the labels of its operands, a generic call the labels of its arguments, and the value of an `if` or `when` the label of its condition, which also makes the condition of a branch in a return position an implicit flow into the result. The message names the declared type and the value's type with their labels. Raise the declared label, or lower the value's label through a policy (`spec/07 §5`). A declared label of the standard library, a field of a kind such as `Header` or `Json` or a parameter of a host operation, cannot be raised: lower the value through a policy. For an HTTP request, a token the API takes as a bearer token goes by the name of its key, `key_name`, which sends `Authorization: Bearer <key>` without the program seeing it; a token the API takes in another header, as `X-Api-Token`, is a header value, so a `secret` one goes through a policy to `internal` first (`spec/24 §1`). In a generic body, a value decided by comparing values of a type parameter `T` carries `label(T*)`, every label of `T`'s type argument, which is not below `label(T)`: it cannot flow into an annotation, a field or a function value's parameter of type `T`, as in `[if a == b then p else q].map(each: k)`. Pass values of `T` through unchanged, or return the decision to the caller (`spec/07 §7` rule 8; the guide's section on labels). In edition `0.4`, an `http` grant of `run grants` with limits needs every `Http` request timed by `internal` data at most, since `HttpError.RateLimited` reveals when each request was made (ADR 0117 IF4, `spec/27 §9`): a request in a function that also works on a `secret` parameter is U4001 at the request; move that work out of the function that makes the request, or remove the limits.

## Failing example

```una
module demo

pub leak(pin: secret Int) -> Int = pin
```

## Fixed example

```una
module demo

pub keep(pin: secret Int) -> secret Int = pin
```
