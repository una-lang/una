# U1011: A constant depends on itself, directly or through other constants

The value of a module constant names the constant itself, or a constant whose value leads back to it.

## Why Una rejects it

From edition `0.5`, a module may declare constants, `[pub] const name: type = value`, whose values the compiler computes at check time (ADR 0126). A constant may name constants declared before or after it, so the compiler evaluates them in the order of their dependencies. A constant that depends on itself has no such order and no value: its computation would never end. The cycle is reported once, at the first constant of the cycle in path order (ADR 0126 rule 4), as U1003 reports a cycle of imports.

## How to fix it

Write one of the values as a literal, or compute it from constants outside the cycle.

## Failing example

`ita.una`

```una
ita demo
  version 0.1.0
  edition 0.5
```

`ita.lock`

```una
lock 1

solver
  encoding "una-smt-1"
  name "z3"
  version "5.1.0"
  logic "QF_UFLIA"
  steps 5000000
  seed 0
```

`src/demo.una`

```una
module demo

pub const width: Int = height + 1

pub const height: Int = width - 1
```
