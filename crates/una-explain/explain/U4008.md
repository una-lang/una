# U4008: A text literal with interpolation in a pattern

A pattern's literal is a constant: a `when` arm `is "…"` and the expression `x is "…"` compare a value with it (`spec/10 §4`). A text literal with interpolation, such as `"{s}"`, is not a constant: its text is computed from the values it interpolates, and those can be labeled. Testing a value against it would decide a branch, or a `Bool`, by those values without their labels (`spec/07 §7` rule 3), so U4008 reports it, in every edition. Compare with `==` instead, whose result carries the labels of both sides, or match a constant.

## Failing example

`src/demo.una`

```una
module demo

pub matches(name: Text, other: secret Text) -> Bool = name is "{other}"
```

## Fixed example

`src/demo.una`

```una
module demo

pub matches(name: Text, other: secret Text) -> secret Bool = name == other
```
