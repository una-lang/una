# U3027: Code that may run forever where it is not allowed to

In edition 0.4, a function that may run forever says so in its header with `diverges` (`spec/26 §5`, ADR 0116 rule 8). `for ever`, and a call of a function that says `diverges`, are legal only in the body of such a function, and not:
- in a lambda, which is an ordinary value that code without `diverges` can call later;
- in a `together` task, since the tasks of a block run one after another in the interpreter;
- in an `on stop` block, which runs once its loop has ended and must end itself;
- in the body of a `for ever` loop, whose every iteration must end (rule 9);
- in a test, except in its `do` line when the test ends with a `stop after N` line, which stops every `for ever` once `N` of their iterations have started (`spec/26 §8`, rule 19).

`diverges` is never inferred, so every header that may run forever says it. The error is at the `for ever` or the call.

## Failing example

`ita.una`

```una
ita demo
  version 0.1.0
  edition 0.4
```

`ita.lock`

```una
lock 1

solver
  encoding "una-smt-1"
  name "z3"
  version "5.1.0"
  logic "QF_UFLIA"
  steps 5000000
  seed 0
```

`src/demo.una`

```una
module demo

pub count() -> Int
=
  let edit n = 0
  for ever
    stop when n > 9
    n = n + 1
  n
```
