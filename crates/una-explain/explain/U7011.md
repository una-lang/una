# U7011: A locked package that is neither in the vendor directory nor in Itaoca

A package of edition `0.4` builds from what its lock pins, with no network (ADR 0122, `spec/30`). Every command that loads the package looks for each locked registry package in the vendor directory of the root, `vendor/ita/<source>/`, and then in Itaoca, the store of fetched packages under `~/.una/itaoca` or the directory `UNA_ITAOCA` names. No command but `una ita` ever opens a connection to fetch one. U7011 reports a locked package that is in neither place, or whose provenance at the lock's resolution point Itaoca does not hold. The repair is to fetch it into Itaoca, then, to build anywhere with `una` alone, `una ita vendor`, which copies it with its provenance into the vendor directory to commit with the lock.
