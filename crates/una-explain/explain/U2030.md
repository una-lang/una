# U2030: A unit conversion without an expected unit, or not exact

`measured()` and `convert()` take the unit they produce from the type their context expects (ADR 0104). `convert()` moves between units of one dimension only by a positive integer ratio that fits the magnitude's integer type: from `Kilometer` to `Meter` it multiplies by 1000. The way down is written out, `(d.magnitude() / 1000).measured()`, so that the truncation of the division shows. `measured()` takes a unitless value, and `convert()` a measured one.

## Failing example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.3"
```

`src/demo.una`

```una
module demo

pub measure Meter

pub measure Kilometer = 1000 * Meter

pub coarse(d: Int of Meter) -> Int of Kilometer = d.convert()
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.3"
```

`src/demo.una`

```una
module demo

pub measure Meter

pub measure Kilometer = 1000 * Meter

pub coarse(d: Int of Meter) -> Int of Kilometer = (d.magnitude() / 1000).measured()
```
