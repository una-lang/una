# U0103: Reserved keyword not available in the package's edition

Some words are reserved for features planned in later versions of Una, and others name constructs from other languages that Una expresses differently. Using one as a keyword or as a name is rejected, and the message says which version plans the feature or which Una construct to use instead (`spec/01 §5`). For example, Una has no `return`: the last expression of a body is its result. A word reserved for a later version, such as `table` or `all`, comes with a repair that renames it, the same way at every occurrence in every module of the package, the names an `import` line lists included: `the_table`, or `Table` where a kind or capability name is expected, with a number added when any module of the package already has that name (`the_table_2`). So applying every edit never makes a name refer to another declaration. In a module path the repair is advice, since the module's file must move too. In edition 0.3 the test declaration is written `test` (ADR 0105), so `example` at the start of a declaration is U0103 there, "`example` is written `test` in edition 0.3", with the exact rewrite of the keyword that `una fix` applies; the declaration's body is read as a test's, and editions 0.1 and 0.2 keep `example`.

## Failing example

```una
module demo

pub double(x: Int) -> Int = return x * 2
```

## Fixed example

```una
module demo

pub double(x: Int) -> Int = x * 2
```
