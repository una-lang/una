# U2041: The value of a constant is not a constant expression, divides by zero, does not fit its type or exceeds the size caps, or its type holds a function type

A module constant's value is something the compiler cannot compute from the source alone, or its computation fails, or its declared type could hold a function.

## Why Una rejects it

From edition `0.5`, a module constant, `[pub] const name: type = value`, names a value that the compiler computes once, at check time, by the language's own semantics (ADR 0126). Every use sees that exact value: the verifier proves contracts with it, and the interpreter and native code use it as a literal. So the value is a **constant expression** (rule 3):

- a literal: an integer, a float, a decimal, a text without interpolation, `true`, `false` or `unit`;
- `-` on a number; `+`, `-`, `*`, `/` and `mod` on integers of one type; `+`, `-`, `*` and `/` on `F64`; `+` and `-` on decimals of one scale;
- `and`, `or`, `not` and the comparisons, where they are defined;
- a constructor of a record or a variant, and a list literal, whose parts are constant expressions;
- parentheses, and the name of another constant.

Nothing else: a call, a method call, a lambda, `if`, `when`, a field access, `checked`, `attempt`, `fail`, `result`, `it`, `error` and an interpolated text are U2041 at the expression, naming the construct. A capability reference is U3005 instead.

The computation is total, and each way it could fail is U2041 at check time, never an obligation: a division or `mod` by zero; a value that does not fit its fixed-width type, as `3_000_000_000` as an `I32`; and a value too large to compute, an integer of more than 4,300 decimal digits or a value of more than 1,000,000 elements, fields and characters together (rule 5), so that no package can make `una check` compute without bound.

A constant's declared type holds no function type, at any depth, a record field included (rule 14): no constant expression is a function, and a constant never carries code or authority.

## How to fix it

Compute the value in a function, `pub root_two() -> F64 = 2.0.sqrt()`, and call it where it is needed; or write the value out as a literal.

## Failing example

`ita.una`

```una
ita demo
  version 0.1.0
  edition 0.5
```

`ita.lock`

```una
lock 1

solver
  encoding "una-smt-1"
  name "z3"
  version "5.1.0"
  logic "QF_UFLIA"
  steps 5000000
  seed 0
```

`src/demo.una`

```una
module demo

pub double(n: Int) -> Int = n * 2

pub const limit: Int = double(500)
```
