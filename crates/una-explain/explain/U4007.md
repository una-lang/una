# U4007: Unknown label category

A label's categories, as in `secret[PII]`, name the kinds of data it protects, and each package declares its categories in `una.toml` under `[labels] categories`, or from edition `0.4` in the `labels` section of `ita.una` (`spec/07 §2`). U4007 reports a category that the package does not declare, in a type's label or an `accepts` clause; a file checked on its own declares none. Declare the category, or correct its name.

## Failing example

`src/demo.una`

```una
module demo

pub keep(t: secret[PII] Text) -> secret[PII] Text = t
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.1"

[labels]
categories = ["PII"]
```

`src/demo.una`

```una
module demo

pub keep(t: secret[PII] Text) -> secret[PII] Text = t
```
