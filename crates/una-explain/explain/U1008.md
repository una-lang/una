# U1008: Module path does not match file path

A package keeps each module at the path its name gives: module `a.b.c` lives in `src/a/b/c.una` (`spec/13 §7`), so a reader and a tool find a module from its name. The diagnostic carries an edit that makes the header match the file; moving the file is the other fix. A file checked on its own is exempt.

## Failing example

`src/events/seating.una`

```una
module events.seats

pub one() -> Int = 1
```

## Fixed example

`src/events/seating.una`

```una
module events.seating

pub one() -> Int = 1
```
