# U2014: Expression outside the refinement language

`where`, `requires` and `ensures` clauses, and the predicate of `checked`, are written in the refinement language, which the verifier decides (`spec/03 §3`): integer, boolean and text literals, parameters, `it`, `result`, field access, `.len`, `+`, `-`, `*` with a literal operand, `/` and `mod` by a nonzero literal, comparisons, `in`, `is` with a variant, `and`, `or`, `not`, `implies`, and calls of predicates. The diagnostic points at the outermost sub-expression outside the language; when the fix is mechanical, such as `x is V` for `x == V` or `x == 1` for `x is 1`, it carries an edit. To use a function in a contract, state what it computes in the contract, or as a predicate.

## Failing example

```una
module demo

pub shift(x: Int) -> Int
  requires abs(x) < 100
=
  x
```

## Fixed example

```una
module demo

pub shift(x: Int) -> Int
  requires x > -100 and x < 100
=
  x
```
