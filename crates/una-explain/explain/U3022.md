# U3022: Labeled operation passed to code that reads it lower

In edition `0.3`, an operation listed in a header's `uses` brackets can carry `gives` and a label: `uses @service_files: Files[owner gives internal[Service]]` says that what `owner` answers through this binding, the value and whether it failed, belongs to the principal `Service` (ADR 0094, `spec/05 §3`). The answer then carries the label, and the flow rules of `spec/07` keep it from reaching anyone below it.

A binding flows to a callee by name or with `with`, and its labels go with it. The callee reads the operation's answers at the label its own header writes, `public` when it writes none. A binding whose operation gives more than that is refused at the call with U3022: the callee would read the answer below its label. The repairs never lower a label: pass another binding whose operation gives at most what the callee reads, when the caller holds one, or raise the `gives` in the callee's header, which then changes what its callers see.

## Failing example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.3"

[labels]
categories = ["Service"]
```

`src/demo.una`

```una
module demo

pub capability Files
  op owner(file: Text) -> Text

owner_seen(file: Text) -> Text
  uses @files: Files[owner]
=
  @files.owner(file)

pub refusal(file: Text) -> internal[Service] Text
  uses @service_files: Files[owner gives internal[Service]]
=
  owner_seen(file) with @files = @service_files
```
