# U2034: `stop` or `skip` outside a loop body, or across a task boundary

In edition 0.4, `stop` ends the innermost `for` loop around it, `stop when c` does so when `c` holds, and `skip` ends the current iteration and goes on to the next (`spec/26 §3`, ADR 0116 rule 6). Each belongs to the body of its innermost loop. It is an error:
- outside any loop body;
- when the innermost loop lies outside the nearest enclosing task: the body of a `together for`, or a branch of `together`, is not a loop for them, so they cannot end an iteration of a loop that runs the task.

A loop inside the task is a loop for them. To end a task's work early, give its block a value with `if`, or put a `for` loop inside the task.

## Failing example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.4"
```

`src/demo.una`

```una
module demo

pub doubled(xs: List[Int]) -> List[Int]
=
  together for x in xs
    if x < 0
      skip
    x + x
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.4"
```

`src/demo.una`

```una
module demo

pub doubled(xs: List[Int]) -> List[Int]
=
  together for x in xs
    if x < 0
      0
    else
      x + x
```
