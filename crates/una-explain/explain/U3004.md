# U3004: Capability used in a pure function

A pure function uses a capability.

## Why Una rejects it

A function without `uses` is pure: it cannot contain any `@` (`spec/04 §2` rule 4). This holds for:

- a public function, which declares every `uses` explicitly;
- a lambda whose expected function type has no `uses` (`spec/04 §6`), such as the argument of `map`.

A private function without `uses` is not pure: its `uses` are inferred (`spec/04 §5`).

## How to fix it

Declare the capability in the header, or in the function type the lambda is written for. The repair is marked as a widening of authority (ADR 0097).

## Failing example

```una
module demo

capability Log
  op write(line: Text) -> Unit

pub report() -> Unit = @log.write("done")
```

## Fixed example

```una
module demo

capability Log
  op write(line: Text) -> Unit

pub report() -> Unit
  uses @log: Log[write]
=
  @log.write("done")
```
