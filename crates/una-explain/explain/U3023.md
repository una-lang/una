# U3023: Header that grants more than its lock in `una.toml`

In edition `0.3`, `una.toml` can lock the `uses` of a public function under `[contracts]` (ADR 0092 rule 8). The lock is the consumer's file, so an edit to the function's header cannot widen what the function may do. The header must be at least as strong as its lock:

- every binding of the header is one that the lock names, with the same capability;
- every operation of a binding is one that the lock lists;
- the header's condition on a locked operation implies the lock's condition. This is a `contract_lock` obligation, and when it is refuted the diagnostic is U3023 too.

A header may drop a binding or an operation, or strengthen a condition: that grants less. The repair is to bring the header back to its lock. Changing the lock is never the repair.

## Failing example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.3"

[contracts]
"demo.update" = ["@catalog: Catalog[price, set_price where not dry_run]"]
```

`src/demo.una`

```una
module demo

pub capability Catalog
  op price(sku: Int) -> Int
  op set_price(sku: Int, cents: Int) -> Unit

pub update(sku: Int, cents: Int, dry_run: Bool) -> Unit
  uses @shop: Catalog[price, set_price]
=
  @shop.set_price(sku, cents)
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.3"

[contracts]
"demo.update" = ["@catalog: Catalog[price, set_price where not dry_run]"]
```

`src/demo.una`

```una
module demo

pub capability Catalog
  op price(sku: Int) -> Int
  op set_price(sku: Int, cents: Int) -> Unit

pub update(sku: Int, cents: Int, dry_run: Bool) -> Unit
  uses @catalog: Catalog[price, set_price where not dry_run]
=
  if not dry_run
    @catalog.set_price(sku, cents)
  unit
```
