# U8001: Internal compiler error (always a bug)

The compiler reached a state it considers impossible: a Core IR that the interpreter cannot evaluate, a query that the solver rejects, or output that cannot be rendered. The program may be right or wrong; the diagnostic says nothing about it, only that `una` failed, with exit code 3. The message names what failed.

One case is not a bug of the compiler but a damaged `una`: `una build` checks the native runtime built into `una` against the digest recorded when `una` was built, before every link, and a runtime that is missing or differs is U8001, with nothing linked (ADR 0124).

## How to fix it

- For a damaged `una`, reinstall `una`.
- Otherwise, report it with the smallest program that reproduces it and the command that was run.

There is no failing example to show here: an input that causes this error is a bug of the compiler, which the fix of that bug removes.
