# U1004: Use of a private declaration from another module

Declarations are private to their module unless they are marked `pub` (`spec/04 §5`), and an import can name only public declarations. The diagnostic points at the imported name, shows the declaration, and carries an edit that adds `pub` to it, marked as a widening of visibility, since every module may then use it (ADR 0097); the other fix, which keeps the module's interface, is to import a public declaration instead.

## Failing example

`src/a.una`

```una
module a

helper() -> Int = 1
```

`src/main.una`

```una
module main

import a (helper)

pub two() -> Int = helper() + 1
```

## Fixed example

`src/a.una`

```una
module a

pub helper() -> Int = 1
```

`src/main.una`

```una
module main

import a (helper)

pub two() -> Int = helper() + 1
```
