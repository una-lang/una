# U7013: No resolution: no release meets a need, or a bound of resolution is exceeded

`una ita lock`, `una ita update` and `una ita add` resolve a package of edition `0.4` by minimal version selection (ADR 0122 rules 23 to 25, `spec/30 §10`): for each identity, a source, a name and a major line, the highest of the least versions that the needs reached ask for. U7013 reports that there is no resolution, and nothing is written: no release of an identity is at or above a need; a selection must be raised past a yanked, advised or avoided release and no later release qualifies, or the one that would is held back by the cooldown, in which case `una ita audit` shows why the release is left, and the repair is to wait out the cooldown rather than to skip it, since a recent yank or advisory is when a hurried release is most dangerous; a pre-release would be selected that no need reached names; a release needs its own identity; a bound of resolution is exceeded, such as 1,000 needs of one release or 10,000 packages in the build list; a source of `sources` with no place this release can read, since it has no https transport, so a source is read from a mirror directory that Itaoca's `mirrors.una` lists as a `file://` URL; or a need of `itaty`, whose root metadata is not built into this release, so nothing it serves can be verified, and no registry is ever resolved from a partial or unverified view of it. `una ita verify` reports U7013 too for a registry package whose copies match the lock but which it does not verify, since it does not hold the owner's key chain. The repair is to name a release that exists, to need a version past one that must be raised, to remove the `avoid` line that excludes the only one, to need fewer packages, or to list a mirror directory for the source in Itaoca's `mirrors.una`. `una check` does not report U7013: it reads the lock, and reports a lock that does not meet `ita.una` as U7009. So this text has no example of its own.
