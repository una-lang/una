# U3033: An operation of `HttpServer` in the effect set of a `together` branch, a `together for` body or a `first of` branch

The branches of `together`, the bodies of `together for` and the branches of `first of` run at once and act for the one task that runs the construct (`spec/19 §1`, `spec/27 §6`). A reply right of `HttpServer` is held by one task at a time (ADR 0123 rule 4), so two branches that could both answer it would answer in an order that timing decides. The effect set of a branch therefore MUST NOT contain an operation of `HttpServer`: `next`, `reply` or `close`, performed in the branch, by a function it calls, by a function value it calls or passes on, by a handler it installs, or by an operation whose handler can perform one (`spec/31 §1`, ADR 0123 rule 5).

The error is at the operation, the call, the function value or the installation. The repair is to compute in the branches and to answer after the construct.

`src/demo.una`

```una
module demo

import std.host (HttpServer, Exchange, Reply)

price(n: internal Int) -> internal Int = n * 3

answer(exchange: internal Exchange, n: internal Int) -> Unit
  uses @server: HttpServer[reply]
=
  together
    let total = price(n)
    let tax = price(n + 1)
  @server.reply(to: exchange.right, reply: Reply(status: 200, headers: [], body: "{total + tax}"))
    if error use unit
```
