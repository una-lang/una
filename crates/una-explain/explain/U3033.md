# U3033: An operation of `HttpServer` in the effect set of a `together` branch, a `together for` body, a `first of` branch, or `handle` or `on_stop` of a `serve` module

The branches of `together`, the bodies of `together for` and the branches of `first of` run at once and act for the one task that runs the construct (`spec/19 §1`, `spec/27 §6`). A reply right of `HttpServer` is held by one task at a time (ADR 0123 rule 4), so two branches that could both answer it would answer in an order that timing decides. The effect set of a branch therefore MUST NOT contain an operation of `HttpServer`: `next`, `reply` or `close`, performed in the branch, by a function it calls or names, by a function value whose type's requirements hold `HttpServer`, by a handler it installs, by an operation whose handler can perform one, or, in a program that imports a name of the server, by a `uses of` parameter that it calls or passes on, whose code its callers choose (`spec/31 §1`, ADR 0123 rule 5).

The error is at the operation, the call, the function value or the installation. The repair is to compute in the branches and to answer after the construct.

The same holds for `handle` and `on_stop` of the module that the `serve` section of `ita.una` names (`spec/31 §7`, ADR 0123 rule 16): in that form the host owns every exchange and answers each request with the reply `handle` returns, so neither function may name `HttpServer`, or a capability whose handlers can perform one of its operations, in its `uses`. The error is at the binding. The repair is to return the reply from `handle`, or to write the server in the language form, with `next` in a `for ever` loop and no `serve` section.

`src/demo.una`

```una
module demo

import std.host (Exchange, HttpServer, Reply)

price(n: internal Int) -> internal Int = n * 3

answer(exchange: internal Exchange, n: internal Int) -> Unit
  uses @server: HttpServer[reply]
=
  together
    let total = price(n)
    let tax = price(n + 1)
  @server.reply(to: exchange.right, reply: Reply(status: 200, headers: [], body: "{total + tax}"))
    if error use unit
```
