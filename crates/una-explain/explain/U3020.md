# U3020: Call into a boundary module whose capability is not granted with `with`

In edition `0.3`, `una.toml` can declare modules of the package as boundaries under `[boundaries]` (ADR 0093): code the package's author does not control, such as a vendored library or a plug-in. No authority crosses a boundary by name. A call into a boundary module, from any module outside its extent, does not meet the callee's `uses` from the caller's bindings by name: every capability the callee needs is granted at the call with `with`, as a rebinding, a narrowed rebinding (`@y[ops]`) or a handler.

The same holds for a function of a boundary used as a value outside it, at the reference, and for a handler of a boundary installed outside it, whose `uses` are granted by another binding of the same `with`. An example's `do` line takes no `with`, so an example outside a boundary can call only boundary functions that need no capability.

The repair is a grant at the call, within the boundary's ceiling (U3021), usually narrowed to what the callee needs. Widening the caller's header is never the repair: the grant is what the consumer reviews.

## Failing example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.3"

[boundaries]
"demo.vendor" = ["Files[read]"]
```

`src/demo/store.una`

```una
module demo.store

pub capability Files
  op read(path: Text) -> Text
  op write(path: Text, data: Text) -> Unit
```

`src/demo/vendor.una`

```una
module demo.vendor

import demo.store (Files)

pub load(path: Text) -> Text
  uses @files: Files[read]
=
  @files.read(path)
```

`src/demo/app.una`

```una
module demo.app

import demo.store (Files)
import demo.vendor (load)

pub open(path: Text) -> Text
  uses @files: Files[read, write]
=
  load(path)
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.3"

[boundaries]
"demo.vendor" = ["Files[read]"]
```

`src/demo/store.una`

```una
module demo.store

pub capability Files
  op read(path: Text) -> Text
  op write(path: Text, data: Text) -> Unit
```

`src/demo/vendor.una`

```una
module demo.vendor

import demo.store (Files)

pub load(path: Text) -> Text
  uses @files: Files[read]
=
  @files.read(path)
```

`src/demo/app.una`

```una
module demo.app

import demo.store (Files)
import demo.vendor (load)

pub open(path: Text) -> Text
  uses @files: Files[read, write]
=
  load(path) with @files = @files[read]
```
