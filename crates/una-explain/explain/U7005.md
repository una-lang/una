# U7005: Trusted module not declared in both header and `una.toml`

A trusted module may declare information-flow policies (`spec/07 §6`), so trust is declared twice: the module's header says `trusted module`, and `una.toml` lists the module under `[trusted] modules`. U7005 reports a module declared in only one of the two places, and a listed module that the package does not have. A file checked on its own has no `una.toml`, so a `trusted module` header there is always U7005.

## Failing example

`src/keys.una`

```una
trusted module keys

pub pepper() -> Int = 7
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.1"

[trusted]
modules = ["keys"]
```

`src/keys.una`

```una
trusted module keys

pub pepper() -> Int = 7
```
