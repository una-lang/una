# U2003: Wrong number of type arguments

A type takes exactly as many type arguments as it has type parameters (`spec/03 §2`): `List[T]` and `Option[T]` take one, `Result[T, E]` takes two, and `Int` takes none, as does a type parameter. The message gives both counts.

## Failing example

```una
module demo

pub size(xs: List) -> Int = 0
```

## Fixed example

```una
module demo

pub size(xs: List[Int]) -> Int = xs.len
```
