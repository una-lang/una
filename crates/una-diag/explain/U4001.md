# U4001: Flow to a lower label

A label says who may observe a value, and data never flows to a lower label (`spec/07 §3`): a value flows into a parameter, a field, an annotated `let`, a policy's `from` type or a function's result only when each position of its type is labeled below the declared label there. Labels follow data: an operator, an interpolation or an equality takes the labels of its operands, a generic call the labels of its arguments, and the value of an `if` or `when` the label of its condition, which also makes the condition of a branch in a return position an implicit flow into the result. The message names the declared type and the value's type with their labels. Raise the declared label, or lower the value's label through a policy (`spec/07 §5`). In a generic body, a value decided by comparing values of a type parameter `T` carries `label(T*)`, every label of `T`'s type argument, which is not below `label(T)`: it cannot flow into an annotation, a field or a function value's parameter of type `T`, as in `[if a == b then p else q].map(each: k)`. Pass values of `T` through unchanged, or return the decision to the caller (`spec/07 §7` rule 8; the guide's section on labels).

## Failing example

```una
module demo

pub leak(pin: secret Int) -> Int = pin
```

## Fixed example

pub keep(pin: secret Int) -> secret Int = pin
