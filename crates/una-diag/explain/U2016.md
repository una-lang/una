# U2016: Opaque predicate called outside `checked`

The solver knows an opaque predicate only as an uninterpreted symbol, so a value obtains an opaque fact only through `checked`, which counts against the module's escape budget and is listed in the build report, or through a capability operation's `ensures` (`spec/03 §4`, `spec/06 §6`, ADR 0042). An opaque predicate is therefore called only as the predicate of `checked` and in the bodies of other opaque predicates. A call anywhere else, in code, in a `requires` or `ensures` clause of a function, in a `reflect` body or in an example, is U2016. The `where` clause of a kind and the clauses of a capability operation name the predicate without establishing its fact, so they may use it. Replace the test with `checked(value, p(it)) else fail <Variant>`.

## Failing example

```una
module demo

pub kind SlugError = | Malformed

predicate opaque valid_slug(t: Text) -> Bool = t.len >= 3

pub kind Slug = Text where valid_slug(it)

pub parse_slug(raw: Text) -> Slug
  fails SlugError
=
  if valid_slug(raw) then raw else fail Malformed
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.1"

[escape_budget]
checked_per_module = 1
```

`src/demo.una`

```una
module demo

pub kind SlugError = | Malformed

predicate opaque valid_slug(t: Text) -> Bool = t.len >= 3

pub kind Slug = Text where valid_slug(it)

pub parse_slug(raw: Text) -> Slug
  fails SlugError
=
  checked(raw, valid_slug(it)) else fail Malformed
```
