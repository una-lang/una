# U0103: Reserved keyword not available in v0.1

Some words are reserved for features planned in later versions of Una, and others name constructs from other languages that Una expresses differently. Using one as a keyword or as a name is rejected, and the message says which version plans the feature or which Una construct to use instead (`spec/01 §5`). For example, Una has no `return`: the last expression of a body is its result. A word reserved for a later version, such as `table` or `all`, comes with a repair that renames it, the same way at every occurrence: `the_table`, or `Table` where a kind or capability name is expected.

## Failing example

```una
module demo

pub double(x: Int) -> Int = return x * 2
```

## Fixed example

```una
module demo

pub double(x: Int) -> Int = x * 2
```
