# U4004: `policy` outside a trusted module

A policy lowers labels, so it is part of the trusted computing base: it is allowed only in a module whose header says `trusted module` and that `una.toml` lists under `[trusted] modules` (`spec/07 §5, §6`). U4004 reports a policy in a module whose header does not say `trusted`; a header that says `trusted` without the listing is U7005. Move the policy to a trusted module, or declare the module trusted in both places.

## Failing example

```una
module demo

pub policy reveal
  from secret Text
  to Text
  via shown
  purpose "show a digest"
  owner privacy

shown(t: secret Text) -> Text = t
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.1"

[trusted]
modules = ["demo"]
```

`src/demo.una`

```una
trusted module demo

pub policy reveal
  from secret Text
  to Text
  via shown
  purpose "show a digest"
  owner privacy

shown(t: secret Text) -> Text = t
```
