# U2017: Use of a binding after it was passed by `take`

In edition 0.2, a parameter declared `take` consumes its argument, and the caller writes `take a` (`spec/17 §3`). After `take a`, every use of `a` is U2017, until an assignment gives `a` a new value; only a `let edit` binding can be reassigned. A binding taken in one branch of an `if` or a `when` counts as taken after the construct. Use the value before passing it, keep a copy of what you need, or assign the binding again.

## Failing example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.2"
```

`src/demo.una`

```una
module demo

pub drain(take items: List[Int]) -> Int = items.len

pub count() -> Int
=
  let items = [1, 2, 3]
  let n = drain(take items)
  n + items.len
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.2"
```

`src/demo.una`

```una
module demo

pub drain(take items: List[Int]) -> Int = items.len

pub count() -> Int
=
  let items = [1, 2, 3]
  let size = items.len
  let n = drain(take items)
  n + size
```
