# U2002: Unknown or ill-formed type

A written type names a built-in type, a kind or a type parameter (`spec/03`). U2002 reports a name that denotes something else, such as a variant or a capability; range sugar on a type other than `Int`; a `fails` clause that names anything but a sum kind without type parameters; an alias defined in terms of itself; and a record or sum kind that contains itself other than through `List` or `Option` fields, since every value must be finite (`spec/03 §2` rule 5). For a recursive field, the diagnostic carries an edit that makes the field optional.

## Failing example

```una
module demo

pub kind Node
  value: Int
  next: Node
```

## Fixed example

```una
module demo

pub kind Node
  value: Int
  next: Option[Node]
```
