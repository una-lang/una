# U3002: Operation not permitted by capability type

A binding `@x: C[ops]` permits only the operations listed in brackets; without brackets it permits all of them (`spec/05 §3`). U3002 reports an operation that the binding in scope does not permit, and a call whose callee needs more operations of `@x` than the caller holds, since passing a capability attenuates it but never widens it (`spec/05 §4`). It also reports `expect performed @x.op` for an operation that the capability of `@x` does not have. Add the operation to the `uses` clause, or drop the brackets to permit every operation.

## Failing example

```una
module demo

capability Log
  op write(line: Text) -> Unit
  op flush() -> Unit

pub finish() -> Unit
  uses @log: Log[write]
=
  @log.flush()
```

## Fixed example

```una
module demo

capability Log
  op write(line: Text) -> Unit
  op flush() -> Unit

pub finish() -> Unit
  uses @log: Log[write, flush]
=
  @log.flush()
```
