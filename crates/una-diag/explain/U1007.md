# U1007: Generated requirement marked active

Agents may propose requirements with `source generated`, but only a person can activate one (`spec/08 §1`): a requirement whose source is `generated` must have `status proposed`. To activate it, a person changes its source to `human`, `policy` or `regulation`. The diagnostic carries an edit that marks the requirement proposed.

## Failing example

```una
module demo

requirement EVENTS_3
  text "An event with no remaining seats is always shown as sold out"
  source generated "task 41"
  owner box_office
  status active
```

## Fixed example

```una
module demo

requirement EVENTS_3
  text "An event with no remaining seats is always shown as sold out"
  source generated "task 41"
  owner box_office
  status proposed
```
