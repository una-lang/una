# U3005: Capability reference used as a value

Capability references are not values (`spec/05 §6`). A bare `@c`, not followed by `.op(...)`, appears only on either side of a `with` binding and after `given @x =` (`spec/02 §8`); it cannot be bound with `let`, passed as an argument, returned, stored in a kind, compared or interpolated. Authority moves only downward along calls, by name: the callee declares the capability with `uses`, and the caller passes it under that name or rebinds it with `with`.

## Failing example

```una
module demo

capability Log
  op write(line: Text) -> Unit

pub run() -> Unit
  uses @log: Log[write]
=
  let sink = @log
  unit
```

## Fixed example

```una
module demo

capability Log
  op write(line: Text) -> Unit

pub note(line: Text) -> Unit
  uses @log: Log[write]
=
  @log.write(line)

pub run() -> Unit
  uses @sink: Log[write]
=
  note("done") with @log = @sink
```
