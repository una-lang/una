# U0101: Unexpected token

The parser found a token that the grammar of `spec/02` does not allow at that point; the message names the token found and what was expected. U0101 also reports brackets left unbalanced within a declaration, chained comparisons such as `a < b < c` (`spec/01 §7`), keywords such as `if` used as names, nested patterns such as `is Some(Circle(radius))`, which v0.1 does not support (bind the field to a name, then match that name in a second `when` inside the arm), literal patterns such as `is Some(0)` (bind the field to a name, then compare it inside the arm), and nesting deeper than 256 levels, where each chained operator counts as one level (ADR 0019). After the error, parsing resumes at the next declaration, so the rest of the file is still checked.

## Failing example

```una
module demo

pub between(x: Int) -> Bool = 0 < x < 10
```

## Fixed example

```una
module demo

pub between(x: Int) -> Bool = 0 < x and x < 10
```
