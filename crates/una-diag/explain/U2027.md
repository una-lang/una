# U2027: An unknown constraint name

A type parameter takes one of the built-in constraints `Eq`, `Ord` or `Integer` (`spec/20 §1`, `§2` rule 3). There are no user traits: a type satisfies a constraint by what it is.

## Failing example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.2"
```

`src/demo.una`

```una
module demo

pub same[T: Equal](a: T, b: T) -> Bool = a == b
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.2"
```

`src/demo.una`

```una
module demo

pub same[T: Eq](a: T, b: T) -> Bool = a == b
```
