# U7002: Invalid `una.toml`

`una.toml` describes the package (`spec/13 §7`, ADR 0021): a required `[package]` table with `name`, `version` and `edition = "0.1"`, and the optional tables `[labels]`, `[trusted]`, `[escape_budget]` and `[run]`. U7002 reports a TOML syntax error, an unknown table or key, a missing required key, and a value of the wrong type or out of range, such as a `[run] entry` that is not a module of the package.

## Failing example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.1"
license = "MIT"
```

`src/demo.una`

```una
module demo

pub one() -> Int = 1
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.1"
```

`src/demo.una`

```una
module demo

pub one() -> Int = 1
```
