# U8001: Internal compiler error (always a bug)

The compiler reached a state it considers impossible: a Core IR that the interpreter cannot evaluate, a query that the solver rejects, or output that cannot be rendered. The program may be right or wrong; the diagnostic says nothing about it, only that `una` failed, with exit code 3. The message names what failed. Report it with the smallest program that reproduces it and the command that was run. There is no failing example to show here: an input that causes this error is a bug of the compiler, which the fix of that bug removes.
