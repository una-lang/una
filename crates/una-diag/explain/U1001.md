# U1001: Unresolved name

Every name must refer to something visible where it is used: a local binding (a parameter, a `let`, a pattern binding or a lambda parameter), a declaration of the module, a name the module imports, or the prelude (ADR 0023). U1001 reports a name that none of these holds, whether it names a value, a type, a capability, a handler, a module or an imported declaration. A variant in a `when` pattern, an `is` test or after `fail` takes its kind from the context, and is checked against that kind instead.

## Failing example

```una
module demo

pub total(x: Int) -> Int = double(x)
```

## Fixed example

```una
module demo

double(x: Int) -> Int = x * 2

pub total(x: Int) -> Int = double(x)
```
