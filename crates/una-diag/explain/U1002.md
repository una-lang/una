# U1002: Duplicate definition

A name is defined once in its scope: the declarations of a module (kinds, variants and capabilities share one namespace; functions, predicates, handlers and policies another), the parameters, fields and operations of one declaration, the requirements of a package and the examples of a module. A local binding cannot rebind another local that is still in scope, so every use of a name inside a function means one binding. A module may reuse a prelude name, and a local may reuse any name that is not local: the inner one wins.

## Failing example

```una
module demo

pub double(x: Int) -> Int
=
  let x = x * 2
  x
```

## Fixed example

```una
module demo

pub double(x: Int) -> Int
=
  let doubled = x * 2
  doubled
```
