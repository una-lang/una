# U1005: Naming convention violation

Names follow fixed conventions (`spec/01 §4`): kinds, variants, capabilities, type parameters and label categories are UpperCamelCase; all other names are lower snake case, without `__` and without a trailing `_`; requirement identifiers are upper snake case ending with `_` and a number, as in `EVENTS_3`. The convention is checked where a name is defined, and the message suggests a name that follows it; rename the uses too.

## Failing example

```una
module demo

pub kind Seat_Count = Int in 0..5000
```

## Fixed example

```una
module demo

pub kind SeatCount = Int in 0..5000
```
