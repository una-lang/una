# U4003: Sink label exceeded

Every argument of a capability operation is a sink with the operation's `accepts` label, `public` when the operation declares none (`spec/05 §2`, `spec/07 §4`): the data an operation sends outside the program, every label of its type, and the program counter under which it runs, must be below that label. Interpolation keeps the labels of what it interpolates, so printing `"id {phone}"` of a `secret` phone to `Console`, which accepts `public`, is U4003. Declassify the data through a policy first, or send it to an operation that accepts its label.

## Failing example

```una
module demo

pub greet(name: secret Text) -> Unit
  uses @console: Console[print]
=
  @console.print("hello {name}")
```

## Fixed example

```una
module demo

pub greet(name: Text) -> Unit
  uses @console: Console[print]
=
  @console.print("hello {name}")
```
