# U2020: A parameter convention (`edit`, `take`) not matched at the call site, or declared where none is allowed

A caller writes `edit p` exactly where the parameter is declared `edit`, and `take a` exactly where it is declared `take`; a marker on a plain parameter, a missing marker, or the other marker is U2020 (`spec/17 §3`). A method receiver follows the same rule, as in `edit total.add(by: 1)`. The argument of `edit` is a place, a binding or a field path of one, and the argument of `take` is a binding. Operations and handlers cannot declare conventions, and neither can predicates: they are U2020 at the declaration.

## Failing example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.2"
```

`src/demo.una`

```una
module demo

pub kind Tally
  count: Int

pub add(edit t: Tally, by: Int) -> Unit
=
  t.count = t.count + by

pub run() -> Int
=
  let edit t = Tally(count: 0)
  add(t, by: 2)
  t.count
```

## Fixed example

`una.toml`

```toml
[package]
name = "demo"
version = "0.1.0"
edition = "0.2"
```

`src/demo.una`

```una
module demo

pub kind Tally
  count: Int

pub add(edit t: Tally, by: Int) -> Unit
=
  t.count = t.count + by

pub run() -> Int
=
  let edit t = Tally(count: 0)
  add(edit t, by: 2)
  t.count
```
