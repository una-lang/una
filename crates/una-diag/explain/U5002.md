# U5002: Obligation unknown

The solver could not decide a proof obligation within the `step_budget` of `verification.lock` or the wall-clock guard of `--solver-wallclock`. In v0.1 an unknown obligation is an error, as a refuted one is (ADR 0008): nothing the solver could not prove is accepted. The message gives the solver's reason. Simplify the goal, give the proof the hypotheses it needs through stronger types or `requires` clauses, or raise the step budget.

## Failing example

`verification.lock`

```toml
encoding_version = "una-smt-1"
solver           = "z3"
solver_version   = "5.1.0"
logic            = "QF_UFLIA"
step_budget      = 1
random_seed      = 0
```

`src/demo.una`

```una
module demo

pub kind Seats = Int in 0..5000

pub shift(seats: Seats, by: Int) -> Int
  ensures result >= by
=
  seats + by
```
