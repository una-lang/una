# U6003: Call depth exceeded

`una run` and `una test` abort when the calls in progress exceed the maximum call depth: 10,000 by default, or the value of `--max-depth` (`spec/11 §7`). The diagnostic points at the call that goes one level too deep. Calls of functions, predicates, lambdas, policies and handler operations all count. Most often a recursion never reaches its base case; a recursion that is only deep can run with a higher `--max-depth`. Running out of depth is outside the noninterference model (`spec/07 §1`).

## Failing example

```una
module demo

countdown(n: Int) -> Int = if n == 0 then 0 else countdown(n - 1)

pub main() -> Unit
=
  let steps = countdown(-1)
  unit
```

## Fixed example

```una
module demo

countdown(n: Int) -> Int = if n <= 0 then 0 else countdown(n - 1)

pub main() -> Unit
=
  let steps = countdown(-1)
  unit
```
